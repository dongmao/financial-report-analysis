## 一、资本周期方法论（制造业/周期行业必备）

### 1.1 资本周期10阶段模型

```
【资本周期10阶段】

1. 高盈利 → 管理层过度自信（把行业景气当自己才能）
2. 需求预测错误率高（好时过于乐观，坏时过于悲观）
3. 高利润使行业放松资本纪律，扩产冲动
4. 高调扩产时股价往往上涨（趋势投资者追捧）
5. 投行提供"润滑剂"（繁荣时帮扩产、低迷时帮整合）
6. 分析师线性外推（在周期性世界中用线性思维）
7. ⚡ 资本支出增加和供给变化之间存在时滞（核心特征！）
8. 过度产能变明显时，需求预测被证伪
9. 利润大幅下滑 → 管理层更换 → 资本支出缩减 → 行业整合
10. 投资减少和供给收缩为利润恢复铺路（理解资本周期的投资者此时开始关注）
```

### 1.2 关键分析工具：资本开支/折旧比

| 比值 | 含义 | 投资含义 |
|------|------|---------|
| = 1 | 仅维持，无扩张 | 行业中性 |
| > 1 | 行业扩产中 | 警惕供给过剩，时滞后产能释放 |
| < 1 | 资本退出中 | 关注均值回归机会 |

### 1.3 资本周期失灵的三种情况

| 情况 | 机制 | 案例 |
|------|------|------|
| **技术颠覆** | 新技术摧毁旧商业模式 | 互联网摧毁广告/零售旧模式 |
| **政府保护** | 国家资本主义下资本周期停止运转 | 国企不会因低回报退出 |
| **全球化影响** | 产业转移导致本地退出后无法享受ROE回归 | 中国制造业转移后无法回到欧美 |

### 1.4 差异化企业 vs 融资型成长企业

| 维度 | 差异化企业 | 融资型成长企业 |
|------|----------|--------------|
| 估值方法 | DCF折现模型 | 远景市值法 |
| 核心关注 | 商业模式差异化 | 资本开支周期 |
| 自购能力 | 有（能回购） | 无（需和市场共生） |
| 典型行业 | 消费品、订阅制 | 新能源、制造业 |
| 估值公式 | 二阶段DCF | 顶点市值=行业空间×渗透率×市占率×景气高点利润率×PE |

**差异化企业三类形态**：
1. **中介/代理机制**：地漏（吉博力）、门锁——中介推荐+客户价格不敏感
2. **数字护城河**：亚马逊、Booking——平台网络效应
3. **订阅制**：Wind模式、实验室设备——刚性需求+高续费率

## 二、景气度投资方法论

### 2.1 核心：交易"边际变化"

```
核心方法：寻找"中短期尤其是季度业绩增速超预期"的公司

关键发现（天风策略跨市场数据）：
├── 全市场一年维度涨跌幅与景气度（扣非增速）呈正相关
├── 大部分A股年度涨幅取决于G而非PEG
└── 增速高≠一定超额收益，但至少代表胜率高且稳定的方向
```

### 2.2 景气度投资三维度

| 维度 | 核心问题 | 判断方法 |
|------|---------|---------|
| **行业景气变化** | 持续还是反转？ | 供需、产能、提价、爆款 |
| **景气持续时间** | 看几年？ | 三年景气才敢年底切换估值 |
| **超预期概率** | 能否beat？ | 在此基础上比较PE/G |

### 2.3 景气度 vs 确定性

| 维度 | 景气度 | 确定性 |
|------|--------|--------|
| 时间维度 | 一年内业绩增速（短期胜率） | 三年业绩能见度（长期胜率） |
| 分析重点 | 行业供需、产能、提价 | 商业模式、竞争格局、行业空间 |
| 估值含义 | 景气高点→极高估值容忍度 | 确定性→决定估值底线 |

**关键警告**：
- 景气高点带来极高估值容忍度（宁王万亿=景气高点线性外推）
- 一旦景气度有逆转迹象，就要抽身或切换下一个高景气赛道
- 高增速需求往往伴随高资本开支，渗透率达30%后进入平稳期

### 2.4 景气股三类分类

| 类型 | 策略要点 | 典型行业 |
|------|---------|---------|
| **新兴成长类** | 景气驱动+看长做短 | 半导体、新能源车 |
| **稳定成长类（GARP）** | 稳定增速+稳定估值 | 医药、消费 |
| **周期成长类** | 周期性业绩+成长估值 | 通信、地产链、TMT |

## 三、估值方法论：期望寿命模型

### 3.1 核心：股票=超长信用债

```
PE和贴现率是等价的，都是期望寿命的结果
├── 不同企业期望寿命不同：越短越低PE，越长越高PE
├── 高久期资产→价值投资（长期持有）
└── 低久期资产→趋势投资（跟着景气行动）
```

### 3.2 估值错误的根源

```
研究员用"无风险利率+5年信用利差"来贴现
但真正该用对应行业30年信用债的贴现率
债券市场没有30年信用债 → 系统性给了过低的贴现率
→ 你看什么都会觉得超级便宜
```

### 3.3 成长vs价值的重新定义

| 类型 | 本质 | 估值特征 |
|------|------|---------|
| **成长股** | 预期寿命长的企业 | 对景气度变动敏感度低→弱周期性 |
| **价值股** | 预期寿命短的企业 | 对景气度变动敏感度高→强周期性 |

三类有确定成长性的标的：30年国债、消费行业头部标的、一二线城市核心地段房产

### 3.4 DCF的膨胀与压缩

```
差异化企业估值的三次膨胀→三次压缩：
1. 行业增速提升→提估值 / 即期增速下降→压缩
2. 高增速年限假设提升→再提 / 长期年限证伪→压缩
3. 折现率下降→最后提 / 折现率抬升→压缩

融资型企业的反身性：
上市高估值→融资→投入→更高现金流→更高估值→再融资
→ 直到供过于求或渗透率增速反转
```

## 四、投资逻辑中的逻辑错误

### 4.1 三类常见逻辑错误

**错误一：混淆客户需求与公司价值**
```
"地产行业永远不会消失，所以我坚定看好地产龙头"
→ 偷换概念：客户需求≠公司价值
→ 从"需求存在"→"行业不死"→"公司不死"→"公司有价值"
   每一步都需要论证
→ 案例：人类获取新闻需求一直存在，但报纸行业几乎消亡
```

**错误二：单变量偏差/过度简化**
```
"经济越不好，考公热情越高，公司生意就越好"
→ 忽略供应能力、竞争格局、管理问题等
→ 需求爆发本身可能是危机导火索：
   供应不足→强行扩张→服务降级→管理问题爆发
```

**错误三：混淆整体与部分**
```
"光伏的本质是能源，能源市场巨大"
→ 偷换概念+混淆整体与部分
→ 正确认知：光伏本质是制造业（用车间流水线方式解决能源需求）
→ 一家公司≠一个行业，一个行业≠一个体系
```

### 4.2 逻辑检验法四问

1. 每个推导步骤是否保持了概念的一致性？
2. 是否存在偷换概念？
3. 是否只盯着单一变量而忽略其他？
4. 整体的属性是否被错误地赋予给了部分？

## 五、高科技投资的"狗鱼模型"

```
芒格从不敢碰高科技→敢于投资的关键转变：掌握了"狗鱼模型"

狗鱼模型：在鳟鱼池中放入凶猛的狗鱼，狗鱼所向披靡
映射：寻找在行业中为客户创造价值的能力远超对手的公司

高科技投资三个层次：
1. 发现科技变革 — 识别划时代的技术进步
2. 判断竞争壁垒 — 没有壁垒的科技进步（航空/铁路）对投资者不利
3. 寻找"狗鱼" — 在科技变革中具有不可匹敌竞争力的公司

关键教训：
├── 科技进步带来的效率提升往往转移到消费者手中
├── 公司的ROE可能因信息不对称消除而被挤压
├── 颠覆性技术出现时，高科技公司也会无一例外地失败
└── 避免被淘汰：远离容易被科技淘汰的公司，或投资"狗鱼"
```

## 六、宏观经济分析框架

### 6.1 多周期叠加定位法

| 周期类型 | 时长 | 核心变量 | 跟踪指标 |
|---------|------|---------|---------|
| **基钦周期** | 40个月 | 库存周期 | PMI、工业企业存货 |
| **朱格拉周期** | 10年 | 设备投资周期 | 重卡/工程机械/机床销量 |
| **库兹涅茨周期** | 18年 | 房地产周期 | 房价指数、土地成交 |
| **康波周期** | 50-60年 | 技术革命周期 | 全要素生产率、技术渗透率 |

### 6.2 房地产与股市的跷跷板效应

```
核心中间变量：全社会无风险收益率

房价上涨期：
├── 房地产投资收益率 = 全社会无风险收益率
└── 抽水股市（2010年后房价指数与沪深300呈负相关）

房价回落期：
└── "一鲸落万物生"：房地产回落整体利好股市
```

### 6.3 A股长牛的条件

```
周期为主导的股市，指数很难长牛
长牛基础：成长+大消费的高占比
成长股最后进化路径：要么变周期，要么成为大消费
最佳配置组合：大消费为主（β）+ 周期股内部竞争有序 + 成长股吸引全球资金（α）
```

### 6.4 美国经济分析框架

```
居民内需三要素：
1. 工作有保证，现金流可期
2. 手上有余量，可超过当期挣钱能力来花钱
3. 未来预期好，资产升值中，花钱意愿强

移民红利：
新增劳动力通过移民而非内生人口→就业增长靠人头而非靠薪资→掐断工资-通胀螺旋
```

## 七、超级周期与产业趋势投资

### 7.1 超级周期定义

```
超级周期 = 技术变革 + 需求爆发，多个向上小周期叠加
典型案例：1996-2001互联网泡沫、2003-2011大宗商品、2019-新能源

两大特点：
1. 周期性：估值坐过山车，前期戴维斯双击，后期业绩兑现时估值快速回归
2. 爆发性：全产业链需求爆发，二三线黑马涨幅远超龙头
```

### 7.2 价值/成长/产业趋势投资总结

| 类型 | 策略要点 |
|------|---------|
| **价值股** | 顺周期中线，只买增速超预期阶段；逆周期长线，买赔率或胜率拐点；不要期望"周期变成长" |
| **成长股** | 注重商业模式带来的持续盈利能力；对利率敏感；成长性也总有一天会消失 |
| **产业趋势** | 大周期由数个小周期构成；估值前高后低；不要相信长期成长性白马；不断挖掘黑马新标的 |

### 7.3 马拉松资本的"衰减率"选股模型

```
价值型股票：投资"周期性修复"，核心指标=增速超预期
成长型公司：投资"盈利持续性"，核心指标=增速下降得比别人更慢

关键区别：ROIC比ROE更能代表资产运营能力
成长型企业正是凭借高ROIC抵御周期性回归
```

## 八、零售电商行业分析

### 8.1 社零数据解读方法

| 要点 | 方法 |
|------|------|
| **基数调整** | 用2021年为基准的复合增速，消除同比基数扭曲 |
| **春节错配效应** | 1-2月合并看，单3月数据可能失真 |
| **线上渗透率** | 线上渗透率同比变化是趋势判断核心，而非绝对增速 |
| **汽车单项影响** | 占限额以上零售1/4，增速反转是社零变动主因 |
| **餐饮vs商品** | 餐饮收入是消费意愿的先行指标 |

### 8.2 跨境电商风险分析

```
关税政策是核心变量（800美元免税门槛变动）
平台模式决定风险敞口：全托管vs半托管
地缘政治风险需纳入估值框架
```

## 九、光伏/储能行业分析

### 9.1 产业链位置与竞争格局

| 环节 | 特征 | 竞争格局 |
|------|------|---------|
| **硅料** | 供给刚性最强，扩产18-24个月 | 价格弹性最大 |
| **硅片** | 龙头主导价格战 | 新势力产能爬坡决定竞争烈度 |
| **电池片** | 技术路线切换期（PERC→TOPCon→HJT） | 不确定性最大 |
| **组件** | 终端定价权 | 品牌+渠道决定溢价能力 |
| **逆变器** | 轻资产高毛利 | 海外渠道+品牌溢价 |

### 9.2 光伏的本质

```
⚠️ 光伏本质是制造业（不是能源业！）
├── 具有强周期性
├── 资本周期10阶段模型完美适用
├── 产能过剩→价格战→利润坍塌→资本退出→均值回归
└── 当前（2024-2025）：资本开支/折旧比已降至<1，供给收缩中
```

### 9.3 光伏关键指标

| 指标 | 含义 | 关注方式 |
|------|------|---------|
| **资本开支/折旧比** | 产能扩张vs退出 | <1=供给收缩信号 |
| **组件单瓦价格** | 盈利底线 | 跌破现金成本=底部信号 |
| **N型TOPCon渗透率** | 技术路线切换 | HJT商业化进度 |
| **硅料产能/组件需求** | 供需比 | >1.5=严重过剩 |
| **库存减值** | 价格下跌风险 | 存货/营收比趋势 |

## 十、分析要点清单

1. **资本周期定位**：行业处于10阶段模型中的哪个位置？资本开支/折旧比是多少？
2. **景气度vs确定性**：当前是赚景气度的钱还是确定性的钱？
3. **估值期望寿命**：用30年信用债利率贴现，而非5年利差
4. **逻辑检验**：是否存在偷换概念、单变量偏差、混淆整体与部分？
5. **多周期叠加**：当前处于基钦/朱格拉/库兹涅茨/康波哪个阶段？
6. **房地产跷跷板**：房价走势如何影响股市资金面？
7. **社零解读**：线上渗透率变化趋势？汽车单项影响？
8. **光伏周期**：是否处于产能过剩→资本退出的阶段？
9. **超级周期判断**：当前产业趋势是否构成超级周期？估值处于前高后低哪个阶段？
10. **"狗鱼"识别**：科技变革中是否有不可匹敌竞争力的公司？
