## 一、加密货币的独特性

```
加密货币 ≠ 股票 ≠ 大宗商品

核心特性：
├── 高波动性：beta极高，与传统资产相关性低
├── 周期性强：减半周期、宏观流动性
├── 监管敏感：政策变化影响巨大
├── 24/7交易：无休市概念
└── 自我托管风险：交易所/协议安全性

估值逻辑与传统资产不同：
├── 无法用DCF（无现金流）
├── 网络价值/交易量（NVT比率）
├── 持有者分布（巨鲸vs散户）
└── 情绪指标主导（恐惧贪婪指数）
```

## 三、周期分析框架

### 3.1 比特币减半周期

```
【BTC四年周期】

周期规律：
├── 减半 → 供给减少 → 价格上涨
├── 涨幅逐次递减（2017:20倍，2021:5倍）
└── 每周期高点 = 下一周期低点的倍数收窄

当前（2024-2025）：
├── 2024年4月减半
├── ETF获批带来的机构需求
└── 宏观流动性边际宽松

关键变量：
├── 机构需求 vs 矿工抛压
├── ETF净流入速度
└── 宏观流动性环境
```

### 3.2 机构 adoption 分析

```
【机构 adoption 阶段】

Stage 1：观望（2020之前）
└── MicroStrategy 开始买入BTC

Stage 2：试探（2020-2023）
└── 特斯拉短暂持仓，PayPal/Visa支持

Stage 3：主流（2024+）
└── 比特币ETF获批
└── 上市公司持仓成常态

信号判断：
├── ETF管理规模（AUM）
├── 新增上市公司持仓
├── 银行托管服务推出
└── 主权基金配置
```

## 四、对标公司与估值

### 4.1 主要公司对照

| 公司 | 类型 | 核心指标 |
|------|------|---------|
| Coinbase | 交易所 | 交易量、托管资产 |
| MicroStrategy | 上市公司持仓 | BTC持仓、折价溢价 |
| Block(Square) | 支付+加密 | Cash App比特币收入 |
| Marathon Digital | 挖矿 | 算力、挖矿成本 |
| Galaxy Digital | 加密金融服务 | 资管规模 |

### 4.2 估值方法

| 类型 | 适用方法 | 关键变量 |
|------|---------|---------|
| 交易所 | EV/Revenue | 交易量、费率 |
| 挖矿 | EV/算力 | 电力成本、BTC价格 |
| 持币公司 | BTC × P/NAV | 持仓NAV |
| 协议 | TVL、活跃地址 | 网络效应 |

## 五、风险提示

```
【加密资产特有风险】

1. 监管风险
   ├── SEC证券定义争议
   ├── 稳定币监管
   └── 各国政策不一致

2. 市场风险
   ├── 杠杆清算cascade
   ├── 流动性深度不足
   └── 交易所安全事件

3. 技术风险
   ├── 量子计算威胁
   ├── 智能合约漏洞
   └── 跨链桥安全

4. 竞争风险
   ├── 新公链崛起
   ├── 传统金融入局
   └── 央行数字货币（CBDC）
```

## 六、分析要点清单

1. **宏观流动性**：美元利率、全球央行政策
2. **减半周期位置**：当前处于哪个阶段？
3. **机构 adoption 进度**：ETF流入速度
4. **链上数据**：巨鲸动向、交易所流入流出
5. **监管动态**：SEC政策、立法进展
6. **竞争格局**：以太坊vs新公链，交易所份额
7. **技术升级**：Layer2采用、ETH升级进展
8. **情绪指标**：恐惧贪婪指数、持仓数据
9. **关联市场**：美股科技股、黄金的相关性
10. **风险预算**：高波动资产配置比例
