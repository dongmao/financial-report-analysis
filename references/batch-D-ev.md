# 新能源/汽车行业研报方法论提炼报告

> 基于204篇海豚研究研报（特斯拉、比亚迪、理想、蔚来、小鹏、零跑、宁德时代等）
> 覆盖时间：2021年-2026年3月

---

## 一、新能源车核心分析维度

### 1.1 销量×ASP的收入拆解法

**方法论核心：** 新能源车企收入=销量×单车均价（ASP），两者往往呈反向关系——降价放量时销量增但ASP降，关键判断是"量增能否覆盖价降"。

**研报案例：**
- **比亚迪（2022-2026）：** 比亚迪从2022年执行"不要利润要市占"的激进定价策略，导致销量暴增但单车均价严重下滑。2025Q4比亚迪单车ASP 13.5万元环比继续下滑1500元，清库存折扣压制了高端化+出海的结构改善红利。海豚君的核心判断框架：**"当销量增速与收入增速的同步性变强，ASP的拖累因素在变小"**（《撕标签时刻》）
- **特斯拉（2025Q2）：** Model Y Juniper换新版上市涨价，带动卖车单价环比提升1800美元至4.18万美元，实现量价齐升。海豚君拆分三个ASP驱动因子：①定价策略（涨价/促销）；②车型结构（Model Y占比提升）；③地区结构（美国高售价区占比提升）。（《特斯拉"送命题"》）

**可复用框架：**
```
收入变化 = 销量变化 + ASP变化
ASP变化 = 定价策略影响 + 车型结构影响 + 地区结构影响
关键判断：量增覆盖价降 → 收入增长；量增不覆盖价降 → "卖得多赚得少"
```

### 1.2 单车毛利/净利的计算方法

**方法论核心：** 海豚君对新能源车企的核心利润指标体系——单车毛利、单车核心经营利润、单车净利，层层穿透。

**研报案例：**
- **比亚迪单车经济模型（2025Q4）：** 单车毛利2.9万元（预期3万），单车净利0.67万元（预期0.71万）。海豚君拆分单车成本=单车折旧+单车可变成本，发现"被动加配"（为满足购置税门槛升级电池续航）推高BOM成本是降本不及预期的核心原因。（《比亚迪：王座失守》）
- **特斯拉单车经济模型（2025Q2）：** 单车折旧3700美元环比下滑600美元（规模效应），单车可变成本3.22万美元环比上行1000美元（关税影响）。最终卖车毛利率15%环比改善2.5个百分点。（《特斯拉"送命题"》）

**可复用框架：**
```
单车毛利 = 单车价格 - 单车成本
单车成本 = 单车折旧（固定成本分摊） + 单车可变成本（BOM+人工）
单车核心经营利润 = 单车毛利 - 单车三费
单车净利 = 单车核心经营利润 + 其他收入 - 其他支出

关键跟踪：固定成本分摊效率（产能利用率）vs 可变成本压力（原材料/关税）
```

### 1.3 补贴退坡/国补政策的影响分析

**方法论核心：** 新能源车补贴政策的影响需分层分析——对总量的影响、对价格带结构的影响、对竞争格局的影响。

**研报案例：**
- **2026年国补新政分析：** 海豚君指出三个关键变化：①从"定额补贴"改为"按车价比例补贴"；②受益结构从低价车转移至中高价车；③旧车持有年限要求收紧防骗补。结论：**更利好理想、蔚来等中高端车企，对比亚迪、吉利等中低端车企不利**。（《补贴新政来了》）
- **美国IRA补贴退坡（2025）：** 7500美元补贴将于9月30日终止，海豚君预判三季度美国需求可能提前释放，四季度销量不可避免下滑，极度依赖Model 2.5的量产进度。（《特斯拉"送命题"》）
- **2026年新能源购置税退坡：** 从免征恢复为减半征收（5%），比亚迪为应对插混纯电续航要求从43公里提至100公里，被迫"加配不加价"，推高BOM成本。（《比亚迪：王座失守》）

**可复用框架：**
```
补贴影响分析三维度：
① 总量：补贴退坡→提前消费→退坡后销量断崖→需新政策平滑
② 结构：补贴方式变化→不同价格带受益程度不同→竞争格局重塑
③ 企业策略应对：加配不加价/清库存折扣/新品定价调整
```

### 1.4 渗透率与增速的关系

**方法论核心：** 渗透率提升≠增速持续，渗透率到一定阶段后增速必然放缓，企业需从"渗透率红利"转向"存量竞争"。

**研报案例：**
- **比亚迪产能利用率模型（2023）：** 海豚君建立产能扩张跟踪框架，测算比亚迪2023年实际产能超310万辆/年，产能利用率97%仍属"满产满销"。但2024年若维持360万辆年产能且满产满销，销量增速将降至20%，"泯然于行业整体增速，比亚迪将告别新能源高渗透的红利期"。（《比亚迪"悬停"》）
- **新能源车行业增速放缓（2024-2025）：** 多篇研报反复提及"增速从200%下降至100%再下降至60%只是基数变大的自然反应"。

### 1.5 电池成本变动对整车毛利的影响

**方法论核心：** 电池成本占整车成本30-40%，锂价→电池成本→整车毛利是新能源车最核心的产业链传导链条。

**研报案例：**
- **宁德时代顺价能力（2022Q2）：** 宁德时代凭借产业链超群地位，二季度对下游涨价后整车厂只有接受的份，压力顺利传导，毛利率恢复速度超预期。核心逻辑：**"只要想做利润，压力传导似乎易如反掌"**。（《走出交易博弈》）
- **比亚迪自产电池优势：** 海豚君指出比亚迪自产电池，成本把控能力更强，电池材料价格从高位回落时，比亚迪毛利率改善"几乎板上钉钉"。（《撕标签时刻》）
- **特斯拉可变成本受关税影响：** 2025Q2关税成本增加3亿美元，其中2亿美元体现在卖车可变成本上，相当于负面拖累卖车成本520美元/辆。（《特斯拉"送命题"》）

### 1.6 出海/海外市场的前景分析

**方法论核心：** 海外市场的分析需区分"规模增量"vs"利润支柱"，ASP和毛利率的国内外剪刀差是关键。

**研报案例：**
- **比亚迪海外"利润压舱石"逻辑（2025Q4）：** 2025年下半年比亚迪海外ASP 18.6万元，是国内12.7万元的1.46倍；海外卖车毛利率28.1%，较国内17.2%高出近11个百分点。海外单车毛利5.2万元，是国内2.2万元的2.4倍。海豚君测算：2026年150-160万辆出口目标，海外单车净利约2万元，海外利润占整车利润近2/3。（《比亚迪：王座失守》）
- **宁德时代全球市占率逻辑（2022）：** 虽然国内市占率因比亚迪自供电池而下滑，但海外装车放量明显，全球市占率反而提升6.2个百分点。（《走出交易博弈》）
- **特斯拉分地区销量结构：** 美国IRA到期前提前消费、中国竞争激烈市占率下滑、欧洲受马斯克政治活动影响品牌价值损伤。（《特斯拉"送命题"》）

**可复用框架：**
```
海外市场分析四要素：
① 出口量及增速 → 规模贡献
② 海外ASP vs 国内ASP → 结构优化
③ 海外毛利率 vs 国内毛利率 → 利润贡献
④ 海外建厂进度 → 避税能力+本地化交付
结论：海外从"规模增量"升格为"利润压舱石"
```

## 二、汽车行业的"量利关系"分析

### 2.1 量增利降 vs 量利齐升的判断逻辑

**方法论核心：** 汽车行业的"量利关系"存在三种状态——量利齐升（渗透率红利期）、量增利降（价格战期）、量稳利升（规模效应释放期），判断企业处于哪个阶段是投资关键。

**研报案例：**
- **比亚迪量利关系演变：** 
  - 2022年前：量增利降——"卖车只过流水，不赚钱"（《拿放大镜来寻找》）
  - 2022H1转折：量利齐升——甩掉燃油车产线包袱后，"利润释放的高质高量，关键是汽车业务利润释放比较强劲"（《撕标签时刻》）
  - 2023-2025：量稳利升——市占率触顶回落，但规模效应持续释放
  - 2025Q4：量降价稳——国内销量承压，靠海外高毛利"救驾"
- **理想的量利关系（2021Q3）：** 新款理想ONE上市即实现高水平毛利率，"同时提高配置和销售价格，消费者感知到了更高的性价比，车企收获了更高的毛利率"（《论赚钱》）

### 2.2 价格战对利润率的传导机制

**方法论核心：** 价格战→ASP下行→毛利率承压→费用端刚性→净利弹性大于毛利弹性。但价格战也可能倒逼效率提升，加速行业出清。

**研报案例：**
- **比亚迪价格战传导：** 2023年新能源车从"供不应求"转向"供过于求"，比亚迪单车收入环比下滑6000元，毛利率从22.8%下滑至20.7%。海豚君判断：**"价格战会对短期利润提升和市场预期带来压力，但经过市场出清后，整体市场格局也将更加清晰"**（《比亚迪：电车价格战》）
- **"反内卷"政策限制：** 2025年行业监管遏制恶性竞争，比亚迪定价策略受到严格审视，"价格战打法束手束脚"，无法通过大幅降价洗牌市场。（《比亚迪：王座失守》）

### 2.3 规模效应在汽车行业如何体现

**方法论核心：** 汽车行业规模效应主要体现在三个层面——摊折稀释、采购降本、费用杠杆。其中摊折稀释是"最硬"的规模效应，费用杠杆可能被可变费用侵蚀。

**研报案例：**
- **比亚迪规模效应穿透（2022H1）：** 海豚君拆分分性质开支后发现，毛利率提升主要靠摊销折旧这种"固定"费用实现——"货物成本基本与收入同增状态，员工费用增速比收入更高，只有总支出中占比前三的折旧和摊销支出率是明显降低的"。（《撕标签时刻》）
- **比亚迪费用杠杆"幻觉"（2022H1）：** 售后服务费随交付量呈现"非线性的爆炸式增长态势"，整体费用端并没有体现出收入释放之后的经营杠杆能力。
- **宁德时代费用杠杆（2022Q2）：** 二季度的规模效应更加明显，单季费用率直接降到了9.6%，首次低于10%。"管理费用相比研发具备更强的经营杠杆效应"。（《走出交易博弈》）

**可复用框架：**
```
规模效应三层次（硬→软）：
① 摊折稀释（最硬）：产能利用率↑ → 单车固定成本↓ → 毛利率↑
② 采购降本（中等）：规模↑ → 供应链议价↑ → BOM成本↓
③ 费用杠杆（最软）：收入↑ → 三费率↓ → 但可变费用（售后/物流）可能侵蚀

反例：售后服务费"非线性爆炸式增长" → 费用杠杆被侵蚀
```

### 2.4 混动/增程 vs 纯电的产品策略分析

**方法论核心：** 技术路线选择（混动/增程/纯电）直接影响车企的ASP、毛利率、市场定位和竞争格局。

**研报案例：**
- **理想增程策略成功：** 增程式解决了里程焦虑，理想ONE上市即实现高水平毛利率。海豚君评价：理想"专注打造符合细分市场需求的高性价比产品"。（《论赚钱》）
- **比亚迪插混霸主地位被围攻：** 比亚迪DM-i平台曾占插混市场60%份额，但长城、吉利、奇瑞集体围攻——"长城的DHT有高低速两挡，吉利有三挡，奇瑞布局了四挡"，技术代差被追平。（《比亚迪"悬停"》）
- **纯电技术普惠化（2026）：** 比亚迪6C级闪充技术系统性下放至15-20万元主力车型，"直接狙击吉利、小鹏在800V下沉市场的布局"。（《比亚迪：王座失守》）

## 三、产业链传导分析

### 3.1 锂价→电池成本→整车价格的传导

**方法论核心：** 锂价是新能源车产业链最上游的"风向标"，传导路径：锂价→正极材料→电芯→电池包→整车BOM→终端售价。

**研报案例：**
- **宁德时代顺价传导（2022Q2）：** "宁王的产业链地位超群，二季度动力电池对下游涨价后，整车厂只有接受的份"。上半年动力电池收入增长156%，其中量贡献115%，价（连续涨价）贡献20%+。（《走出交易博弈》）
- **比亚迪自供电池的"天然屏障"：** 电池材料价格高位时，比亚迪自产电池成本把控能力更强；材料价格从高位回落时，比亚迪毛利率改善"几乎板上钉钉"。（《撕标签时刻》）
- **产业链利润分配逆转：** 2022年二季度"产业链上大多数整车公司都是利润的至暗时刻——电池厂开始传递电池涨价，同时整车厂交付的订单还是零售价没有涨价之前的整车，导致大多数公司的毛利极其难看，最终赚钱的都是电池材料公司"。（《撕标签时刻》）

### 3.2 产能利用率与毛利率的关系

**方法论核心：** 汽车行业产能利用率直接决定摊折效率，是毛利率的"隐性开关"。

**研报案例：**
- **比亚迪产能利用率跟踪框架：** 海豚君建立了比亚迪产能扩张跟踪模型，通过公开信息采集还原产能扩张进度。2022年产能利用率超100%（超负荷），2023H1回落至97%（仍属"满产满销"），2024年若无法维持满产满销则毛利率提升停滞甚至回落。（《比亚迪"悬停"》）
- **特斯拉产能利用率影响：** 2025Q1因新款Model Y停产和爬坡，存在"闲置产能和其他与爬坡相关的成本"，直接拖累毛利率。Q2爬坡完成后单车折旧环比下滑600美元。（《特斯拉"送命题"》）
- **"反内卷"下的产能闲置风险：** 比亚迪2024年底将拥有超500万辆年产能，但"以南北大众巅峰时期的400万销量来看，客观上，比亚迪要继续实现满产满销的难度很大"。（《比亚迪"悬停"》）

**可复用框架：**
```
产能利用率 → 毛利率传导模型：
- 利用率>100%：超负荷，毛利率高位但不可持续
- 利用率90-100%：满产满销，规模效应充分释放
- 利用率70-90%：产能开始闲置，摊折压力增大
- 利用率<70%：大量产能闲置，毛利率显著承压

跟踪指标：在建工程/固定资产、库存周转天数、产销比
```

## 四、估值方法

### 4.1 PS vs PE的选择逻辑

**方法论核心：** 新能源车企估值应区分发展阶段——亏损期用PS（收入规模代表市场地位），盈利期切换至PE（利润代表经营质量）。

**研报案例：**
- **成长股vs价值股估值逻辑：** 海豚君明确指出，"对成长股的估值一定是要选择动态估值而不是静态估值，用三年、五年甚至十年的公司利润、现金流来确定估值"。2020年宝马销量是蔚来54倍，但市值相当；丰田销量是特斯拉19倍，但特斯拉市值碾压丰田。（《新能源车：高估值背后》）
- **国内车企P/S倍数普遍不到1倍：** 海豚君指出，国内车企"基本上都没有把智驾变现的预期打进估值，仍然还是一个基于卖车硬件端的估值"。（《终极拷问》）

### 4.2 亏损车企如何估值

**方法论核心：** 亏损车企的估值需结合"UE拐点法"（Unit Economics拐点）和"对标法"（对标成熟期企业的终局市值）。

**研报案例：**
- **零跑"穿越生死线"框架：** 毛利率转正是新势力"穿越生死线"的关键标志。海豚君持续跟踪零跑毛利率从负转正的过程，核心判断"毛利率持续转不了正→车圈小米何时领跑"vs"毛利率成功转正→零跑终于开始穿越生死线"。（多篇零跑研报）
- **蔚来"生死局"框架：** 单季爆亏60亿后，核心问题不是亏损额而是"能否挺进决赛圈"——是否有足够的资金、产品力和品牌力存活到行业出清后。（《蔚来：单季爆亏60亿》）
- **小鹏"脱胎换骨"框架：** 烂业绩照样涨，因为市场在定价"转型预期"而非当期利润。（《烂业绩照样涨》）

**可复用框架：**
```
亏损车企估值四步法：
① 判断UE拐点：单车毛利何时转正？单车净利何时转正？
② 判断行业出清时间：价格战何时结束？尾部玩家何时退出？
③ 终局市值测算：对标成熟车企的销量×单车净利×PE
④ 折现回当前：考虑时间价值和不确定性折价
```

### 4.3 特斯拉的"科技溢价"

**方法论核心：** 特斯拉的估值包含三部分——卖车基本盘 + Robotaxi/FSD + Optimus，后两者构成"科技溢价"，且与造车基本面逐渐脱钩。

**研报案例：**
- **特斯拉估值分拆（2025）：** 海豚君将特斯拉估值拆分为三部分：
  - 卖车业务：7000亿（假设全球市占率13%，25倍PE）
  - FSD业务：4200亿（25倍P/S，含自车订阅+第三方授权）
  - Robotaxi：1700亿（美国市场80%市占率，20倍PE折现）
  - **总计约1.4万亿，"即使已经将无人驾驶技术成熟的所有乐观预期打满，特斯拉也就是1.4万亿市值上下"**（《终极拷问》）
- **股价与造车基本面脱钩：** "走到330的股价，很大程度上都来自于robotaxi业务的正常推进，以及定价了大部分的星辰大海业务robotaxi和optimus上，和汽车基本面的表现实则关联度有些脱钩"。（《特斯拉"送命题"》）
- **"短期无法证伪"逻辑：** FSD V14+HW5.0和Optimus Gen3的量产拐点在四季度末到2026年初，"属于短期无法证伪，但远期仍然很宏伟"。（《特斯拉"送命题"》）

**可复用框架：**
```
特斯拉"科技溢价"估值法：
估值 = 卖车PE估值 + FSD PS估值 + Robotaxi PE估值 + Optimus期权价值

关键参数：
- 卖车：全球市占率、单车净利、PE倍数
- FSD：存量车数、订阅渗透率、月费、P/S倍数
- Robotaxi：市占率、GTV规模、净利率、PE倍数
- Optimus：量产时间、年产量、单价（纯期权定价）

风险：科技溢价越大→与造车基本面脱钩越严重→高股价低预期下超预期不值得庆贺
```

## 五、共性方法论

### 5.1 预期差含金量判断案例

**高含金量预期差（改变长期逻辑）：**
- **比亚迪甩掉燃油车包袱（2022H1）：** 市场预期比亚迪只是销量增长，实际利润释放来自结构性改善（燃油车产线停用→摊折下降→毛利率可持续提升）。海豚君判断"比亚迪的利润释放可以有比较强的连续性和持续性"。（《撕标签时刻》）
- **宁德时代顺价能力（2022Q2）：** 市场担忧毛利率持续下行，实际宁王产业链地位使其可以轻松涨价传导压力，毛利率恢复速度超预期。（《走出交易博弈》）

**低含金量预期差（短期因素或不可持续）：**
- **比亚迪外汇收益（2022H1）：** 9亿外汇收益"公司是卖车的，又不是炒外汇的，这个收益没有什么值得称道的，也没有永续的可持续性"。（《撕标签时刻》）
- **特斯拉Model Y Juniper涨价（2025Q2）：** 一次性换新涨价带来ASP回升，但后续面临IRA退坡和关税影响，"在Model 2.5四季度正式上市之前，卖车基本面预计都会一直呈现承压状态"。（《特斯拉"送命题"》）

**中等含金量预期差（方向确定但幅度不确定）：**
- **比亚迪海外高毛利反哺国内（2025Q4）：** 方向上确定（海外ASP和毛利率远高于国内），但幅度取决于海外销量占比提升速度和国内竞争烈度。（《比亚迪：王座失守》）

### 5.2 三层利润穿透案例

**方法论核心：** 从GAAP归母利润→Non-IFRS/Non-GAAP利润→核心经营利润，层层剔除非经营性因素，还原真实经营能力。

**研报案例：**
- **比亚迪（2022H1）：** 36亿归母利润 → 剔除9亿外汇收益 → 27亿"实际利润"，再剔除比亚迪电子疲软利润 → 汽车业务利润释放才是核心。（《撕标签时刻》）
- **理想（2021Q3）：** GAAP利润 vs Non-GAAP利润"双双转正"——市场更关注Non-GAAP口径，因为剔除了股权激励等非现金费用。（《论赚钱》）
- **比亚迪（2025Q4）：** 整体归母净利润93亿 → 剔除比亚迪电子3.8亿（远低于预期12亿） → 整车业务贡献约90.4亿 → 单车净利0.67万元。（《比亚迪：王座失守》）

## 六、行业专属分析工具箱

### 6.1 新能源车企财报分析标准流程

```
第一步：收入端
  - 总收入 vs 预期（超/符合/低于）
  - 汽车业务收入拆分：销量×ASP
  - ASP变化归因：定价/车型结构/地区结构

第二步：利润端（核心）
  - 毛利率：汽车毛利率 vs 整体毛利率
  - 单车经济模型：单车价格-单车成本=单车毛利
  - 单车成本拆分：单车折旧（固定）+ 单车可变成本

第三步：费用端
  - 三费率变化：研发/销售/管理
  - 规模效应验证：费用率是否随收入增长而下降
  - 关注售后服务费等"非线性增长"的可变费用

第四步：利润质量
  - 三层利润穿透：GAAP→Non-GAAP→核心经营利润
  - 剔除非经营性因素：外汇/投资收益/政府补贴

第五步：前瞻判断
  - 产能利用率趋势 → 毛利率方向
  - 出海vs国内结构 → 利润结构
  - 新品周期 → 销量拐点
  - 补贴/政策变化 → 需求影响
```

### 6.2 电池产业链分析框架

```
上游（锂矿/正极材料）：
  - 锂价走势是产业链"风向标"
  - 供给端：矿端产能释放节奏
  - 需求端：新能源车+储能装机量

中游（电池厂）：
  - 市占率变化（国内vs全球）
  - 顺价能力（能否将成本传导给整车厂）
  - 技术路线（磷酸铁锂vs三元锂vs固态电池）

下游（整车厂）：
  - 自供电池 vs 外供电池的选择
  - 电池成本占整车成本比例
  - 电池技术迭代对产品力的影响
```

### 6.3 Robotaxi/FSD估值框架

```
收入端：
  - 存量车数 × 订阅渗透率 × 月费（FSD订阅模式）
  - 第三方授权车数 × 抽成比例 × 月费
  - Robotaxi单车日均GTV × 运营天数

成本端：
  - 智驾硬件成本增量
  - 远程安全员/地勤人员成本
  - 运维/清洗/检测等额外成本

UE模型关键：
  - Robotaxi自运营成本率 vs 网约车司机成本率
  - 技术成熟度 → 运营时间/接单量/覆盖区域

估值方法：
  - 卖车：PE估值
  - FSD：P/S估值（软件属性）
  - Robotaxi：PE估值（运营属性）
  - Optimus：期权定价（高度不确定）
```

## 七、跨行业可复用的通用方法论

### 7.1 "合并同类项"警示法
当公司开始合并披露口径、降低业务可见度时，往往是业务承压的信号。比亚迪从2022年开始将汽车和电池业务合并披露，"导致汽车业务的可见度下去很多"。

### 7.2 "产销配速"跟踪法
对于重资产行业（汽车、光伏等），建立产能扩张跟踪模型，定期更新产能利用率，判断"满产满销"是否可持续。

### 7.3 "价格战→行业出清→格局改善"判断法
价格战短期利空但长期可能利好龙头：①短期利润承压→②尾部玩家退出→③竞争格局改善→④龙头利润率回升。

### 7.4 "海外利润反哺国内"分析框架
对于国内竞争激烈的行业，海外市场的高ASP和高毛利率可以成为"利润压舱石"，关键看海外销量占比提升速度。

### 7.5 "科技溢价"与"基本面脱钩"的判断
当股价走势与当期基本面脱钩，意味着市场在定价远期愿景，此时需关注：①愿景实现的关键里程碑；②"短期无法证伪"的时间窗口；③愿景兑现的概率和时点。
