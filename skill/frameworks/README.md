## 🎯 框架使用指南

### 统一结构
每个框架包含以下部分：
1. **📊 核心指标** — 业务量、盈利、效率等关键KPI
2. **🔍 分析维度** — 商业模式、竞争格局、技术趋势
3. **📈 估值指标** — 相对/绝对估值方法、关键比率
4. **🎯 重点公司与对标** — 行业龙头、国际对标
5. **🚨 风险提示** — 行业/公司/宏观/技术风险
6. **📝 分析要点清单** — 具体操作步骤和检查项

### 分析流程建议
1. **确定行业** → 选择对应框架文件
2. **收集数据** → 按框架"核心指标"部分要求
3. **多维分析** → 使用"分析维度"结构化思考
4. **估值判断** → 参考"估值指标"方法
5. **风险评估** → 对照"风险提示"检查清单
6. **要点核对** → 完成"分析要点清单"所有项目
