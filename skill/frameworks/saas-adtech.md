# SaaS与广告技术分析框架

> 覆盖：AppLovin/Unity/Palantir/Salesforce/Snowflake/ServiceNow/BOSS直聘、SaaS通用方法论、广告技术ROAS分析
>
> 数据来源：基于海豚研究229篇SaaS/金融科技/平台研报深度提炼

---

## 一、SaaS行业的核心分析逻辑

```
SaaS公司 ≠ 传统软件公司 ≠ 互联网平台
核心差异：
├── 估值锚定在"增速+利润率"的阶梯上
├── 增速下滑时估值会被暴力重定价
├── NRR（净收入留存率）是最核心的运营指标
├── Rule of 40（增速+利润率≥40%）是健康度基准
└── AI对SaaS的影响是双面的——替代vs增强
```

### 1.1 SaaS增长阶梯模型

```
【SaaS增长三阶段】

高速增长期（>30%增速）
├── 估值锚：PS/EV-Revenue（10x+）
├── 关注指标：ARR增速、NRR、TCV
├── 风险：增速降档但估值未切换 → "估值陷阱"
├── 典型公司：AppLovin 2023-2025（Axon 2.0推动增速52%+）
└── 代表金句："池塘与大海的规模区别"——TAM切换逻辑

中速增长期（15-30%增速）
├── 估值锚：EV/EBITDA + 增速溢价（5-8x EV/Revenue）
├── 关注指标：利润率拐点、FCF转正
├── 风险：靠并购维持名义增速，但有机增速放缓
├── 典型公司：Unity "SaaS+广告"双轮驱动
└── 代表金句："双轮失速"——一个引擎熄火就崩盘

低速增长期（<15%增速）
├── 估值锚：PE/FCF（从成长股切换为价值股）
├── 关注指标：分红/回购收益率
├── 风险：市场仍用成长股估值框架 → "越跌越贵"
├── 典型公司：Salesforce "SaaS龙头已沦为价值股"
└── 代表金句："AI Agent的美梦仍可望不可及"
```

## 二、核心指标体系

### 2.1 SaaS通用指标

| 指标 | 含义 | 关注方式 |
|------|------|---------|
| **ARR（年化经常性收入）** | 收入规模 | 增速比绝对值更重要 |
| **NRR（净收入留存率）** | 客户粘性 | >120%=极强；<100%=流失 |
| **有机增速（Organic Growth）** | 剔除并购后增速 | 名义增速vs有机增速差距=并购依赖度 |
| **Rule of 40** | 增速+利润率 | ≥40%健康；<30%需警惕 |
| **FCF/收入** | 现金流质量 | >20%=优秀 |
| **客户数×ARPU** | 收入驱动 | 新客 vs 老客增购 |

### 2.2 广告技术特有指标

| 指标 | 含义 | 关注方式 |
|------|------|---------|
| **ROAS** | 广告主侧投资回报 | AppLovin "1/5的报价获得同样高的ROAS" |
| **eCPM** | 平台侧变现效率 | 趋势比绝对值重要 |
| **广告加载率** | 变现杠杆 | 加载率↑但用户体验↓的平衡 |
| **TAM切换进度** | 从小市场切到大市场 | AppLovin：游戏广告→电商广告（TAM 10x扩大） |

### 2.3 "小而美"SaaS的抗周期指标

| 指标 | 含义 | 关注方式 |
|------|------|---------|
| **行业集中度** | 竞争格局 | 低集中度=有成长空间 |
| **客户切换成本** | 粘性 | 数据/工作流锁定=高切换成本 |
| **AI替代风险** | 技术威胁 | AI降低门槛→垂类SaaS护城河被侵蚀 |
| **跨周期韧性** | 经济敏感度 | 招聘淡季仍保持增长=强韧性 |

## 三、AI对SaaS的影响判断

### 3.1 替代vs增强判断框架

```
【AI对SaaS的影响矩阵】

AI增强路径（利好）：
├── AI提升产品效率 → 客户粘性增加 → NRR提升 → 估值提升
├── 典型：AppLovin Axon 2.0提升广告变现效率
├── 典型：Copilot推动M365客单价+8.4%
└── 条件：SaaS掌握独占数据+AI增强而非替代中间层

AI替代路径（利空）：
├── AI绕过中间层 → 客户自建方案 → ARR流失 → 估值下降
├── 典型：Salesforce Agent层壁垒存疑
├── 典型：美图等垂类SaaS"小而美没活路"
└── 条件：SaaS产品同质化+无独占数据+客户自建成本低

判断标准三问：
1. 该SaaS是否掌握独占的行业数据？
2. 客户自建AI方案的成本是否高于续费？
3. AI是增强现有工作流还是绕过SaaS中间层？
```

### 3.2 SaaS的"AI护城河"评估

| 护城河层级 | 典型 | AI威胁程度 |
|-----------|------|-----------|
| **数据壁垒** | Salesforce Data Cloud | 🟢 低——AI需要数据，掌控数据=掌控AI入口 |
| **工作流壁垒** | ServiceNow IT工作流 | 🟡 中——AI可能优化但难以完全替代复杂工作流 |
| **网络效应** | Snowflake数据共享 | 🟢 低——数据越多客户越离不开 |
| **纯工具型** | 美图/简单设计工具 | 🔴 高——AI直接提供同等功能 |

## 四、广告技术深度分析

### 4.1 ROAS×eCPM双维度拆解

```
广告技术分析 = TAM切换逻辑 + 竞争壁垒拆解 + 变现效率

TAM切换逻辑（核心增长叙事）：
├── AppLovin案例：游戏广告（TAM~150亿）→ 电商广告（TAM~3000亿）
├── "从池塘切到大海"——哪怕只吃1%也是巨幅增长
└── TAM 10x扩大是10倍股的核心驱动

竞争壁垒拆解：
├── 数据积累：用户画像×行为数据×转化数据
├── 算法优势：AppLovin Axon 2.0 vs Unity追赶
├── 注意力时长：游戏激励广告30-60s不可跳过 vs 社交5-10s
└── 渠道多样性：避免单一渠道依赖（Meta eCPM持续上涨）

变现效率三因子：
├── ROAS（广告主侧）
├── eCPM（平台侧）
└── 加载率（用户体验侧）
```

### 4.2 AppLovin vs Unity对比分析

| 维度 | AppLovin | Unity |
|------|---------|-------|
| **AI引擎** | Axon 2.0（自研，领先） | 试图追赶 |
| **核心优势** | 游戏广告数据+算法积累 | 游戏引擎+开发者生态 |
| **增长叙事** | TAM切换（游戏→电商） | SaaS+广告双轮驱动 |
| **估值逻辑** | 增速52%+ → PS高溢价 | 双轮失速 → 估值坍塌 |
| **关键判断** | "1/5报价获得同样高ROAS" | "能抄出Applovin的钞能力吗？" |

## 五、金融科技SaaS的特殊分析

### 5.1 TPV×Take Rate双因子拆解

| 分析维度 | 核心问题 | 判断方法 |
|---------|---------|---------|
| **TPV驱动力** | 用户数×人均交易额×频次 | 增速是否可持续 |
| **Take Rate驱动力** | 手续费率+增值服务占比 | 天花板在哪里 |
| **增长质量** | TPV驱动（健康）vs Take Rate驱动（需警惕天花板） | 对比行业均值 |

### 5.2 支付毛利结构分层

```
支付公司毛利三层：
├── 支付处理毛利（低毛利，~1-2%）
├── 增值服务毛利（中毛利，~30-50%）
└── 金融产品毛利（高毛利，借贷10%+利率）

健康趋势：高毛利业务占比↑ → 整体利润率扩张
风险信号：靠低毛利业务冲营收规模，利润被稀释

案例Block三层结构：
├── 支付手续费（低毛利）
├── 订阅服务（中毛利）
├── 比特币交易（近零毛利但贡献营收规模）
→ "Cash App独木难撑"
```

### 5.3 加密公司"三阶段"业务模式

```
阶段①：交易驱动
├── 收入=交易量×手续费率
├── 周期性极强，随BTC价格波动
├── 估值：EV/Sales（2-5x）
└── 典型：Coinbase早期

阶段②：生态驱动
├── 收入=用户钱包数×AUM×变现率
├── 稳定币利息分成更具持续性
├── 估值：EV/EBITDA
└── 典型：Coinbase当前转型

阶段③：基础设施驱动
├── 收入=API调用量×B2B客户数
├── 从"周期股"向"平台股"切换
├── 估值：PS+平台溢价
└── 典型：Coinbase远期愿景

关键判断："链上火了，卖水人真能躺赢？"
→ 能否从交易收入转型为生态收入
```

## 六、亏损公司的UE拐点估值法

### 6.1 UE拐点判断

```
UE = 单用户收入 - 单用户获客成本 - 单用户服务成本

拐点前：UE<0 → 估值="能不能活"
├── 估值锚：PS、EV/Revenue
├── 现金储备/月度消耗率 < 12个月 → 必须切换战略
└── 市场关注：融资能力、烧钱速度

拐点时：UE=0 → 估值切换点
├── 估值弹性最大！从"生存担忧"到"盈利弹性"
└── 典型：SEA所有板块一个季度内全部扭亏

拐点后：UE>0 → 估值="能长多大"
├── 估值锚：PE、EV/EBITDA
├── 估值提升 = 利润率改善斜率 × 增长保持度
└── 风险：拐点后增长放缓（如SEA的GMV萎缩）
```

### 6.2 "增长→利润"切换三件套

```
1. 提变现率（Shopee 3P变现率一口气+160bp）
2. 砍营销费用（SEA营销费用-61%）
3. 裁员/控费（B站渐进式利润改善）

市场反应预判：
├── 激进切换（SEA）：V型反弹，"活下去的担忧完全解除"
├── 渐进改善（B站）：稳步修复，更可持续
└── 半吊子（Block）：利润改善但增长放缓，"控费能挤利润但非长远之计"
```

## 七、估值方法

### 7.1 SaaS估值阶梯

| 增速阶段 | 估值锚 | 倍数参考 | 切换信号 |
|---------|-------|---------|---------|
| >30% | EV/NTM Revenue | 10-20x | 增速降至25%以下 |
| 15-30% | EV/EBITDA | 20-35x | 有机增速降至15%以下 |
| <15% | PE/FCF | 15-25x | FCF转正且稳定 |

### 7.2 Rule of 40检验

```
增速 + 利润率 ≥ 40% → 估值有支撑
增速 + 利润率 30-40% → 估值承压
增速 + 利润率 < 30% → 估值危险区

增速溢价模型：
├── 增速每高5pct，倍数+1-2x
├── AppLovin：CAGR 25%+ → EV/Adj. EBITDA=33x，"横向不低但不含明显泡沫"
└── Salesforce：增速降至个位数 → 从EV/Revenue切换到PE
```

### 7.3 确定性折价+成长溢价（加密/新兴SaaS）

```
确定性折价：商业模式不成熟/监管不明 → 估值打5-7折
成长溢价：TAM巨大+先发优势 → 给予1.5-2x溢价
两者叠加 → 估值波动极大 → 适合"区间交易"而非"目标价交易"
```

## 十、分析要点清单

1. **判断增长阶段**：公司处于SaaS增长阶梯的哪个阶段？
2. **估值匹配检验**：估值方法是否与增速阶段匹配？增速降档后估值是否切换？
3. **有机vs名义增速**：增长靠内生还是并购？并购依赖度越高，估值倍数应越低
4. **AI替代vs增强**：AI是增强产品还是替代中间层？掌握独占数据=护城河
5. **NRR趋势**：NRR>120%=极强粘性；NRR<100%=客户流失信号
6. **Rule of 40**：增速+利润率是否≥40%？
7. **TAM切换**：是否在从小市场切到大市场？切换进度和成功率如何？
8. **UE拐点**：亏损公司的UE何时转正？拐点后的利润弹性有多大？
9. **加密/金融SaaS特有**：TPV驱动vs Take Rate驱动？哪个更可持续？
10. **管理层信号**：指引是否超预期？高管是否减持？（Circle教训）
