## 一、商业服务业的底层逻辑

```
商业服务公司 ≠ 消费品公司
核心差异：
├── 驱动因素：企业支出 vs 居民消费（更稳定但有周期性）
├── 规模效应：固定成本高，边际成本低
├── 粘性高：企业切换供应商成本高
└── 监管特殊：金融属性带来额外风险

四大子行业的共同分析框架：
1. 规模 × 效率 = 盈利能力
2. 用户获取成本 vs 生命周期价值
3. 宏观周期敏感度高
4. 政策/监管影响大
```

## 二、金融科技：核心指标

### 2.1 主要商业模式

| 模式 | 代表公司 | 核心收入 | 关键指标 |
|------|---------|---------|---------|
| **支付** | Block/PayPal | 交易手续费 | TPV × Take rate |
| **券商** | 富途/老虎 | 交易佣金+利息 | 入金用户数 × ARPU |
| **信贷** | Affirm/乐信 | 利息收入+服务费 | 贷款余额 × 利率 × 坏账率 |
| **SaaS金融** | 东方财富 | 基金代销+增值 | 基金保有量 × 市占率 |

### 2.2 金融科技关键指标

**📊 支付平台（Block/PayPal）**
| 指标 | 含义 | 关注方式 |
|------|------|---------|
| **TPV（总支付额）** | 平台总交易规模 | 增速反映商业活跃度 |
| **Take rate** | 手续费率 | 竞争压力vs提价能力 |
| **活跃用户数** | 用户规模 | 增速和留存 |
| **比特币收入** | Block特有 | 波动性大，关注毛利 |
| **Cash App增长** | 超级App进展 | 金融生态粘性 |

**💹 互联网券商（富途/老虎）**
| 指标 | 含义 | 关注方式 |
|------|------|---------|
| **入金用户数** | 付费客户 | 增速反映市场吸引力 |
| **资产余额** | 客户资产管理规模 | 市场涨跌影响 |
| **ARPU** | 单用户收入 | 变现深度 |
| **利息收入占比** | 融资融券业务 | 利率环境和风险偏好 |
| **客户资产留存** | NDR | 用户粘性 |

### 2.3 金融科技特有风险

```
【金融科技风险评估】

1. 信贷质量风险
   ├── 坏账率（NCL）趋势
   ├── 拨备覆盖率
   └── 贷款迁徙率

2. 监管风险
   ├── 牌照要求变化
   ├── 合规成本上升
   └── 反洗钱/KYC要求

3. 市场风险
   ├── 资本市场活跃度影响交易量
   ├── 利率环境
   └── 汇率波动
```

## 三、物流快递：核心指标

### 3.1 商业模式与竞争格局

```
【快递行业格局】

CR3 = 中通 + 圆通 + 韵达（电商件）
CR4 = 顺丰 +京东物流（时效件+电商件）

竞争维度：
├── 价格竞争：单票收入持续下降
├── 服务竞争：时效达成率、投诉率
└── 网络竞争：末端网点密度

关键趋势：
├── 电商增速放缓 → 件量增长减速
├── 价格战缓和 → 单票毛利修复
└── 业务延伸：快递→快运→供应链
```

### 3.2 物流快递关键指标

| 指标 | 含义 | 关注方式 |
|------|------|---------|
| **件量增速** | 业务增长 | 电商渗透率×各家份额 |
| **单票收入** | 定价能力 | 价格战缓和信号 |
| **单票成本** | 成本控制 | 自动化/装载率提升 |
| **市场份额** | 竞争地位 | CR3集中度 |
| **资本开支/营收** | 扩张激进度 | 产能扩张节奏 |
| **现金流/净利润** | 盈利质量 | 资本密集型验证 |

## 四、招聘人力资源：核心指标

### 4.1 商业模式

```
【在线招聘的商业逻辑】

用户：求职者（免费） + 企业（付费）

变现路径：
├── 基础服务免费
├── 增值服务：简历下载、职位置顶
├── 效果广告：按点击/简历付费
└── 延伸：培训、背调、SaaS

蓝领 vs 白领：
├── 蓝领：高流动性、高频次、低ARPU
└── 白领：低流动性、低频次、高ARPU
```

### 4.2 招聘公司关键指标

| 指标 | 含义 | 关注方式 |
|------|------|---------|
| **MAU** | 用户规模 | 活跃度 |
| **付费企业数** | 客户规模 | 续费率 |
| **ARPU** | 单企业付费 | 增值服务渗透 |
| **收入增速** | 成长性 | 市场份额变化 |
| **NDR** | 净收入留存 | 用户粘性 |
| **蓝领占比** | 用户结构 | 产业变迁 |

## 五、房地产居住服务：核心指标

### 5.1 行业周期定位

```
【房地产周期分析】

顶部信号：
├── 成交量持续萎缩
├── 库存去化周期拉长
├── 开发商现金流紧张
└── 土地溢价率下降

底部信号：
├── 政策放松（首付/利率/限购）
├── 刚需积压后释放
├── 库存去化加快
└── 土地市场回暖

当前（2024-2025）：政策底已现，销售底待确认
```

## 七、分析要点清单

### 金融科技
1. **信贷质量**：坏账率趋势，是否在可接受范围？
2. **监管环境**：牌照、合规成本对盈利的影响？
3. **市场竞争**：份额是否稳定，获客成本是否上升？
4. **宏观敏感度**：资本市场活跃度、利率环境？
5. **国际化**：海外市场拓展进展？

### 物流快递
6. **价格战位置**：单票收入是否见底？
7. **成本下降空间**：自动化/装载率还能提升多少？
8. **新业务布局**：快运/供应链/国际进展？
9. **资本开支节奏**：产能扩张是否过于激进？
10. **现金牛 vs 成长**：成熟业务能否支撑新业务投入？

### 招聘
11. **用户粘性**：求职者找到工作后流失率？
12. **变现深度**：免费→付费转化率如何提升？
13. **蓝领拓展**：从白领向蓝领延伸的壁垒？

### 房地产
14. **政策判断**：当前处于周期哪个阶段？
15. **资产质量**：土地储备的城市分布是否健康？
16. **融资能力**：现金流能否覆盖债务？
17. **新业务转型**：物业服务/租赁住宅的成长性？
18. **格局演变**：民企 vs 国企的份额变化？
