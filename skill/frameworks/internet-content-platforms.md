## 一、互联网公司的四大商业模式

互联网公司看似相似，但盈利模式有本质差异，**分析前先正确归类**：

| 模式 | 核心收入 | 代表公司 | 关键变量 |
|------|---------|---------|---------|
| **平台双边市场** | 佣金+广告 | 阿里/美团/Sea | Take rate × GMV |
| **内容流量平台** | 广告+会员+增值 | B站/快手/微博 | DAU × 时长 × eCPM |
| **游戏管道商** | 游戏流水+分发 | 网易/腾讯游戏 | Pipeline × 递延收入 |
| **工具/技术服务** | SaaS订阅+广告 | Unity/AppLovin | ARPU × 付费转化率 |

## 二、核心指标体系

### 2.1 通用指标（所有互联网公司必看）

| 指标 | 含义 | 分析要点 |
|------|------|---------|
| **收入及增速** | 顶层增长 | ≥8个季度趋势，区分有机增长vs并购 |
| **毛利率** | 成本结构 | 内容成本/分成成本占比是最大变量 |
| **Non-GAAP经营利润** | 核心盈利 | 区分GAAP vs Non-GAAP（SBC通常很大） |
| **研发费用率** | 创新投入 | 过低=缺乏长期竞争力；过高=短期利润压力 |
| **MAU/DAU及增速** | 用户规模 | 加速度（增速变化）比绝对值更重要 |

### 2.2 分类型核心指标

**📺 内容/社交平台（B站/快手/微博）**

| 指标 | 含义 | 关注方式 |
|------|------|---------|
| **DAU/MAU** | 用户粘性 | >50%为强粘性 |
| **日均使用时长** | 注意力份额 | 直接决定广告库存上限 |
| **MPU/ARPPU** | 付费转化 | MPU/MAU = 付费转化率 |
| **广告eCPM** | 广告定价 | 衡量变现效率 |
| **内容分成成本** | 创作者激励 | 占收入比趋势——上升=争夺内容 |

**🎮 游戏公司（网易/腾讯/米哈游）**

| 指标 | 含义 | 关注方式 |
|------|------|---------|
| **递延收入** | 未来收入能见度 | **关键先行指标！** |
| **Pipeline质量** | 在研游戏储备 | S/A级潜力产品数量 |
| **老游戏衰减曲线** | 存量游戏健康度 | 是否超预期衰减？ |
| **版号获取** | 新游上线硬约束 | 追踪每月版号发放 |

**💰 平台型公司（阿里/美团/Sea）**

| 指标 | 含义 | 关注方式 |
|------|------|---------|
| **Take Rate** | 货币化率 | 最关键！Trend比绝对值重要 |
| **GMV/GTV** | 交易总额 | Take rate = Revenue/GMV |
| **AOV** | 客单价 | 反映消费力和品类结构 |
| **NDR** | 净收入留存 | 存量用户的付费意愿 |
| **履约成本/单均** | 本地生活特有 | 美团vs抖音竞争的关键战场 |

**🤖 AI/搜索平台（百度/字节）**

| 指标 | 含义 | 关注方式 |
|------|------|---------|
| **在线营销收入** | 搜索广告基本盘 | vs 行业广告大盘 |
| **AI云收入** | 智能云业务 | 增速和客户数 |
| **AI应用用户量** | 新产品商业化 | 早期信号：调用次数/付费转化 |

**🚗 出行/本地生活（Uber/滴滴/DoorDash）**

| 指标 | 含义 | 关注方式 |
|------|------|---------|
| **GTV/订单量** | 平台总交易额 | 增速+市场份份额 |
| **Take rate** | 抽佣比例 | 提升空间 vs 竞争压力 |
| **UE模型** | 单均经济 | 收入-履约成本-补贴 = 单均贡献 |
| **每订单营销费用** | 获客效率 | 是否在改善？ |

## 四、典型归因逻辑库

### 4.1 收入超预期归因

| 归因 | 典型表述 | 验证方法 |
|------|---------|---------|
| 广告主预算增加 | "宏观回暖带动广告复苏" | 检查多平台同步性 |
| 电商大促拉动 | "双11/618超预期" | 对比季节性系数 |
| 新业务爆发 | "XX进入规模化放量期" | 独立增速+占比 |
| 提价/变现效率提升 | "ARPU提升" | 用户数vs ARPU背离验证 |
| 低基数效应 | "恢复性增长" | 看CAGR而非单季同比 |

### 4.2 收入低于预期归因

| 归因 | 典型表述 | 验证方法 |
|------|---------|---------|
| 宏观消费疲软 | "社零下滑拖累大盘" | 查看同期社零数据 |
| 竞争加剧 | "价格战导致让利" | Take rate+毛利率变化 |
| 监管影响 | "XX政策导致调整" | 区分一次性vs持续性 |
| 业务主动收缩 | "放弃低质量增长" | 利润率是否同步改善 |
| 流量见顶 | "用户增长个位数" | DAU/MAU趋势图 |

### 4.3 利润暴增/暴跌归因

**暴增的可能原因**：
- ✅ 规模效应 → 费用率下降（好！可持续）
- ✅ 业务结构优化 → 高毛利占比提升（好！）
- 🟡 营销费用缩减 → 短期利好但损长期（中性）
- 🟡 投资收益/资产处置 → 一次性（排除后看真实盈利）
- 🔴 大幅裁员/削减研发 → 损害长期竞争力（警惕！）

**暴跌的可能原因**：
- 🔴 激进投资新业务 → 战略性亏损（看进展判断合理性）
- 🔴 竞争导致补贴增加 → 恶性循环风险
- 🟡 一次性计提 → 排除后看运营利润
- 🟡 汇率波动 → 非经营性问题

## 五、平台特有场景分析

### 5.1 本地生活大战（美团 vs 抖音）

```
【竞争分析框架】

1. 市场份额（三方数据交叉验证）
   - GMV市占率、订单量市占率、DAU市占率

2. UE模型对比
   - 美团：成熟期，追求盈利
   - 抖音：进攻期，可以接受短期亏损换份额

3. 三方博弈
   - 商户端：多平台运营成本和收益
   - 消费者端：补贴敏感度和忠诚度
   - 骑手端：运力供给和成本

4. 终局推演
   - 能否共存？（参考打车市场）
   - 还是一方通吃？
```

### 5.2 游戏"猪周期"判断

```
当某游戏公司连续2-3个季度业绩承压时：

Step 1: 判断是" Pipeline断档"还是"老游戏衰减超预期"
Step 2: 如果是Pipeline问题——下一款重磅新品何时上线？
Step 3: 如果是老游戏衰减——运营手段能否延缓？
Step 4: 估算新游戏的流水天花板（IP热度 × 品类 × 竞品）
Step 5: 递延收入的变化是重要先行信号
```

### 5.3 出海业务分析（Temu/TikTok Shop）

```
【出海分析框架】

1. 增长 vs 盈利的权衡阶段
   - 当前：抢占市场（烧钱换增长）
   - 关键追踪：每新增用户的边际成本

2. 地缘政治风险
   - 美国监管/关税政策
   - 欧盟GDPR/DMA合规

3. 与国内业务的协同/资源争夺
   - 是否在"抽血"国内业务？
   - 还是形成新增长曲线？
```

### 5.4 监管风险评估矩阵

| 监管领域 | 影响范围 | 分析方法 |
|---------|---------|---------|
| 反垄断 | 平台型公司 | 罚款金额 + 互联互通执行力度 |
| 数据安全 | 所有科技公司 | 合规成本占收入比 |
| 内容审核 | 社交/内容平台 | 对推荐算法的影响 |
| 未成年人保护 | 游戏/社交 | 游戏时长限制对收入冲击 |
| 劳动保障(骑手) | 本地生活平台 | 社保试点 → 履约成本上升 |

## 七、电商平台深度分析补充

### 7.1 补贴效率分析法（拼多多/电商通用）

```
核心指标：一元销售费用对应的GMV金额

关键发现：
├── 百亿补贴后，单位营销费用产出GMV持续上升 → 补贴效率提高
├── LTV/CAC模型验证：拼多多用户获客成本约94元，单用户年贡献64元，1.5年回本
├── 电商平台活跃用户"只增不减"的规律 → LTV模型的安全垫假设
└── 补贴可持续性判断：Non-IFRS利润转正 + 经营现金流持续为正 = 模式自证
```

### 7.2 国补效应的"透镜分析法"（京东/电商通用）

```
核心判断：利润超预期需追问驱动力的可持续性

国补传导机制（京东2025Q1案例）：
├── ① 国补拉低通电售价 → 销量飙升
├── ② 通电产品本就是利润品类 → 商城毛利率从16.2%提升到16.8%
├── ③ 国补带来自然流量 → 营销费用可控（只增14% vs 收入增16%）
└── 关键判断："资本估值不是看当期利润有多好，更重要的是动因有多少是可持续的"

验证方式：
├── 公司增速 vs 行业增速对比是判断α的关键
├── 京东通电增速17% vs 社零家电+通讯行业增速29% → 只是行业β而非公司α
└── 国补转弱信号：供应商在困难时期给予更优惠价格也是一次性因素
```

### 7.3 外卖单均UE拆解法（美团/本地生活）

```
核心框架：
单均收入 = 配送收入 + 佣金收入 + 广告收入
单均成本 = 配送成本
单均利润 = 收入 - 成本 - 补贴

美团案例：
├── 2021Q3每送一单毛亏损1.07元 → 2023H1每单毛亏损0.31元
├── 不补贴时每单挣1.8-2元
├── C端单均补贴约1.5元 + 配送端0.44元 = 蓄水池约2元
└── 终局推算：5300万单/天×1.2元≈230亿年利润；8000万单/天×1.0元≈290亿

关键洞察：
├── 单均补贴是"蓄水池"概念——可调节，是利润弹性来源
├── 防守型业务（如拼好饭）不能用盈利标准评估，而用"避免的损失"衡量
└── 广告收入 vs 佣金收入增速差是竞争格局的先行指标
```

### 7.4 低频→高频导流逻辑（京东做外卖/跨品类分析）

```
核心逻辑：高频业务（外卖）→ 提升APP打开率 → 为低频实物电商导流
├── 外卖本质是"投流和获客成本"
├── 但外卖UE极差：规模效应拉满的美团也只有低个位数利润率
└── 判断新业务是"战略投入"还是"无效内卷"：
    ├── 是否有可复用的基础设施（骑手网络）
    └── 是否有防守逻辑（防止美团侵蚀即时零售）

亏损天花板量化：
├── 外卖日单量500万 × 单均亏损2元 = 日亏1000万，年亏36.5亿
└── 股东回报（10%+回购+分红率）与新业务亏损的拉扯：
    高股东回报限制下跌空间，但新业务亏损限制上行空间
```

### 7.5 直播+广告合并看待法（快手/内容平台通用）

```
当业务结构变化导致单一指标失真时，合并相关业务看总量趋势：
├── 快手直播收入下滑看似利空
├── 但实际是"电商导流性直播收入→广告收入"的转移
├── 原因：小店通等精准投放工具推出，打赏买流量→公域广告投放
└── 合并看：直播+广告收入合计增速基本稳定

收入口径转移的信号：
├── 直播→广告 → 平台控制力增强（公域>私域）
└── 电商货币化率提升路径：限制第三方链接 → 体系内成交比例↑ → 佣金率强化
```

### 7.6 用户天花板判断法（拼多多/电商通用）

```
关键判断：用户天花板不是竞争对手，而是最大参照系

拼多多案例：
├── 天花板不是淘宝，而是微信
├── 三层获客逻辑：①显性面（微信裂变）②隐性面（下沉市场触网）③供给面（淘宝商家溢出）
└── 关键思维转变：从"性价比用户"到"用户的性价比需求"

可复用方法：
├── 用户天花板 = 渗透率最高的参照系 × 可触达比例
├── 获客驱动因素需拆解：平台主动获客 + 宏观趋势红利 + 竞争对手战略失误
└── 下沉市场用户触网与硬件渗透率高度相关
```

## 八、腾讯/阿里特色分析补充

### 8.1 腾讯四柱收入拆解法

```
游戏：本土 vs 海外 → 手游 vs 端游 → 新游增量 vs 老游衰减 → 递延收入推算流水
广告：社交广告 vs 媒体广告 → 视频号增量 vs 传统存量 → 加载率×eCPM
金科与企服：支付 vs 云业务 → 央行备付金倒推支付增速 → 剔除视频号佣金推算云
数字内容：付费用户×ARPPU → 付费率结构性改善
```

### 8.2 阿里分层收入拆解法

```
平台零售（淘宝天猫）：客户管理收入 → Take rate × GMV → 剥离出GMV增速和变现率变动
重资产零售（盒马/饿了么/菜鸟/Lazada）：收入增速 + 亏损率 → 判断投入效率
新故事线（云/菜鸟/大文娱）：收入增速 + 亏损收窄进度 → 判断独立造血能力

关键洞察："边线炮火收回，转投主战场" → 65%平台利润率可能成为新常态
```

### 8.3 毛利率变动的三维归因

```
1. 收入结构效应：高毛利业务占比提升（游戏+广告占比↑→综合毛利率↑）
2. 成本结构效应：带宽成本↓、服务器折旧优化、内容成本压缩
3. 业务自身改善：云业务减少低毛利分包、广告减少联盟分成、游戏减少外部渠道分发
```

## 九、分析要点清单

1. **先分类**：是平台/内容/游戏/SaaS中的哪类？盈利模式有何不同？
2. **跟踪月度数据**：MAU、GMV等高频数据
