## 一、消费行业的分析心法

### 1.1 底层逻辑

```
消费股分析 = 宏观消费周期 × 行业渗透率阶段 × 公司竞争地位

第一层：宏观 — 钱包效应
├── 可支配收入增速 → 决定消费总盘子
├── CPI/PPI → 影响成本端和定价策略
├── 就业率/失业率 → 影响消费信心
└── 社零总额增速 → 消费大盘温度计

第二层：中观 — 行业生命周期
├── 导入期（渗透率<10%）：看用户教育和市场培育
├── 成长期（10-50%）：看增速和份额抢夺
├── 成熟期（50-70%）：看格局优化和盈利能力
└── 衰退期/再成长（>70%）→ 看第二增长曲线

第三层：微观 — 公司竞争力
├── 品牌力（定价权 = 溢价能力）
├── 渠道力（触达效率）
├── 产品力（创新速度和成功率）
└── 组织力（执行力）
```

### 1.2 消费分析"三板斧"

**第一板斧：价量拆解**
```
收入变动 = 价格(ASP) × 销量
- ASP↑ + 销量↑ → 提价被接受 → 🟢 强品牌力
- ASP↓ + 销量↑ → 以价换量 → 🟡 看毛利率是否稳住
- ASP↓ + 销量↓ → 最差情况 → 🔴 价格战+需求萎缩
- ASP↑ + 销量↓ → 提价过度 → 🟡 观察后续季度
```

**第二板斧：同店销售（SSS）**
```
同店销售额(SSS) = 同店客流量 × 客单价

SSS是最重要指标，比总收入更有意义：
- 总收入增长可能来自开新店（不可持续）
- SSS增长才是真正的"内生增长"
- SSS连续负增长 = 基本面出问题的重要信号
```

**第三板斧：渠道库存周期**
```
渠道库存健康的四个阶段：
1. 补库期：出货 > 终端销售 → 收入虚高 ⚠️
2. 平衡期：出货 ≈ 终端销售 → 收入反映真实需求 ✅
3. 去库期：出货 < 终端销售 → 收入低于真实 ⚠️
4. 底部反转：库存去化完毕 → 拐点信号 🔄
```

## 二、核心指标体系

### 2.1 通用消费指标

| 指标 | 含义 | 正常范围/警示 |
|------|------|-------------|
| **收入及增速** | 顶层增长 | >10%良好；<5%需警惕 |
| **毛利率** | 产品盈利能力 | 因品类差异大（白酒70%+ vs 超市20%） |
| **经营利润率** | 运营效率 | >15%优秀；<5%需关注费用控制 |
| **ROE** | 股东回报 | >15%优秀；<8%需关注 |
| **存货周转天数** | 库存健康度 | 趋势比绝对值重要 |

### 2.2 分业态核心指标

**🍷 高端白酒/奢侈品**
| 指标 | 含义 | 关注方式 |
|------|------|---------|
| **批价** | 渠道出货价 | 反映真实需求和库存健康度 |
| **动销** | 实际销售速度 | 经销商库存月数 |
| **批零价差** | 渠道利润空间 | 倒挂=库存积压信号 |
| **预收款** | 蓄水池调节 | 同比变化反映渠道信心 |

**☕ 大众饮品（瑞幸/蜜雪/东鹏）**
| 指标 | 含义 | 关注方式 |
|------|------|---------|
| **单店收入** | 同店效率 | 选址优化效果 |
| **闭店率** | 门店质量 | 异常高=选址模型出问题 |
| **原材料成本率** | 供应链议价 | 规模化后是否下降 |
| **下沉市场渗透** | 扩张空间 | 门店密度仍有空间 |

**👟 运动服饰（安踏/李宁/Lululemon）**
| 指标 | 含义 | 关注方式 |
|------|------|---------|
| **库销比** | 库存健康度 | 4-5个月为警戒线 |
| **折扣率** | 促销力度 | 折扣加深=需求疲软 |
| **直营占比** | 渠道掌控力 | 直营比例提升=毛利率改善 |
| **DTC收入占比** | 直连消费者 | 用户数据价值 |

**🏨 酒店旅游（华住/携程/Airbnb）**
| 指标 | 含义 | 关注方式 |
|------|------|---------|
| **Occ（入住率）** | 产能利用率 | 70-80%为良好区间 |
| **ADR（平均房价）** | 定价能力 | 反映品牌力和供需 |
| **RevPAR** | 每可用房收入 | Occ × ADR，最核心指标 |
| **会员复购率** | 用户粘性 | 自有渠道占比 |

**🛒 零售/超市（Walmart/Costco/Target）**
| 指标 | 含义 | 关注方式 |
|------|------|---------|
| **SSS增长** | 同店销售 | 客流量vs客单价分解 |
| **电商渗透率** | 全渠道转型 | 线上收入占比 |
| **会员费收入** | Costco特有 | 会员续约率（>90%） |
| **坪效（$/sq ft）** | 门店效率 | 纵向对比趋势 |

**📺 广告营销（分众传媒）**
| 指标 | 含义 | 关注方式 |
|------|------|---------|
| **刊例价变动** | 媒体定价 | 提价=竞争壁垒体现 |
| **客户结构** | 行业分布 | 互联网/消费品/金融占比 |
| **点位扩张** | 媒体资源 | 一二线城市覆盖密度 |
| **应收账款周转** | 回款质量 | 客户账期健康度 |

## 四、典型归因逻辑

### 4.1 消费"暴雷"的五种模式

| 模式 | 典型信号 | 案例 |
|------|---------|------|
| **渠道压货** | 预收款下降+收入虚高 | 部分酒企曾出现 |
| **价格倒挂** | 批零价差消失/为负 | 动销不畅的预警 |
| **库存积压** | 库销比持续攀升 | 运动服饰去库存期 |
| **需求透支** | 集中消费后连续疲软 | 某些节假日消费后 |
| **竞争失位** | 市场份额持续下滑 | 产品力老化 |

### 4.2 消费复苏判断框架

```
【消费景气度信号灯】

🟢 领先指标（早于财报1-2季度）
├── 社零增速环比变化
├── 消费者信心指数
└── 电商大促数据（双11/618）

🟡 同步指标（与财报同期）
├── SSS增速
├── 毛利率环比变化
└── 渠道库存水平

🔴 滞后指标（晚于财报）
├── 龙头公司业绩增速
├── 行业整体利润率
└── 资本开支节奏
```

## 六、品牌力四维评估法

### 6.1 四维框架

```
维度1：定价能力
├── 同等产品能否持续定价高于同行？
├── 案例：Lululemon瑜伽裤定价为阿迪耐克2-3倍，毛利率超同行10pct+
├── 案例：茅台定价权来源于"供给稀缺+先款后货+批价远高于出厂价"
└── 量化指标：毛利率与同行的差距

维度2：提价传导能力
├── 成本上升时能否顺利转嫁？需求弱时能否不降价？
├── 终端折扣率变化趋势：折扣收窄=品牌力增强
├── 案例：茅台批价与出厂价之间的"安全垫"是定价权最直接的体现
└── 量化指标：终端折扣率趋势

维度3：复购率/客户粘性
├── 复购率越高→品牌力越强→定价权越稳固
├── 营销费率与同行的差距：低营销费+高增速=强品牌力
├── 案例：Lululemon营销费率明显低于同行却实现高坪效
└── 量化指标：营销费率与同行的差距

维度4：溢价来源的稳定性
├── 功能溢价（最低）→ 情感溢价（中等）→ 社交溢价（最高）
├── 社交溢价最稳定：茅台的社交属性远强于其饮用属性
├── 案例：名创优品从"10元店"→"IP零售"，通过IP联名将品类认知升级
└── 量化指标：存货周转天数（周转快=需求旺盛=品牌力强）
```

### 6.2 品牌力量化指标速查

| 指标 | 含义 | 强品牌力特征 |
|------|------|------------|
| **毛利率与同行差距** | 品牌溢价最直接的量化体现 | 高于同行10pct+ |
| **营销费率与同行差距** | 低营销费+高增速=强品牌力 | 低于同行3-5pct |
| **终端折扣率趋势** | 折扣收窄=品牌力增强 | 折扣率持续收窄 |
| **存货周转天数** | 周转快=需求旺盛=品牌力强 | 快于同行20%+ |

## 七、IP零售/潮玩行业分析

### 7.1 核心逻辑

```
IP零售 = IP价值 × 渠道效率 × 用户情感连接

泡泡玛特模式：
├── IP创造（Molly/Dimoo等）→ 盲盒销售 → 用户收集+社交
├── 核心指标：IP数量×单IP收入、复购率、会员贡献占比
├── 增长逻辑：IP矩阵扩张 + 海外扩张 + 品类延伸

名创优品模式：
├── 从"10元店"→"IP零售"的品类认知升级
├── 核心指标：IP联名产品占比、海外门店增速、毛利率改善
├── 关键转型：通过IP联名提升品牌调性，从性价比→品质感
```

### 7.2 IP零售关键指标

| 指标 | 含义 | 关注方式 |
|------|------|---------|
| **IP数量×单IP收入** | IP矩阵价值 | 老IP衰减 vs 新IP增长 |
| **复购率** | 用户粘性 | 盲盒模式的高复购是否可持续 |
| **会员贡献占比** | 核心用户价值 | 会员体系质量 |
| **海外收入占比** | 增长空间 | IP跨文化接受度 |
| **IP联名产品占比** | 品类升级进度 | 名创优品转型的核心指标 |

## 八、运动品牌DTC深化分析

### 8.1 DTC转型的利润结构影响

```
DTC（Direct-to-Consumer）转型对利润的影响：
├── 收入端：直营零售价>>批发价 → DTC占比↑ → 收入规模↑
├── 毛利率：直营毛利率60-70% vs 批发毛利率40-50% → 毛利率显著提升
├── 费用端：直营需要承担零售运营成本（租金/人员/库存）→ 费用率↑
└── 净利率：DTC转型初期净利率可能下降，规模效应后才改善

关键判断：DTC转型是否"增收不增利"？
├── 看DTC毛利率 - 零售运营费用率是否>批发毛利率
├── 看库存风险是否可控（直营需自行承担库存）
└── 安踏案例：DTC转型成功，毛利率从45%提升至55%+
```

## 九、酒店/旅游RevPAR三因子分析

### 9.1 RevPAR拆解深化

```
RevPAR = Occ（入住率）× ADR（平均房价）

三因子关系：
├── Occ↑ + ADR↑ → 强势周期（供不应求）
├── Occ↑ + ADR↓ → 促销换量（需求恢复初期）
├── Occ↓ + ADR↑ → 品牌溢价（高端酒店抗周期）
└── Occ↓ + ADR↓ → 衰退期

华住案例：
├── 2023年恢复：Occ率先恢复→ADR随后跟上→RevPAR超2019年
├── 会员体系：自有渠道占比提升→减少OTA佣金→利润率改善
└── 加盟vs直营：加盟是"轻资产"扩张，直营是"利润锚点"
```

## 十、分析要点清单

1. **宏观验证**：社零增速、CPI、消费者信心指数
2. **价量拆解**：ASP和销量各自贡献多少？
3. **渠道健康**：库存周期在哪个阶段？
4. **竞争格局**：份额在集中还是分散？
5. **品牌定价权**：能否持续提价而不流失客户？
6. **扩张边界**：还有多少城市/人群可以渗透？
7. **成本控制**：原材料涨价能否传导至下游？
8. **资产负债表**：渠道压货是否掩盖真实需求？
9. **现金流验证**：经营性现金流是否与净利润匹配？
10. **估值比较**：当前估值在历史区间的什么位置？
11. **品牌力四维**：定价能力/提价传导/复购率/溢价来源稳定性
12. **IP零售分析**：IP矩阵价值、品类升级进度、跨文化接受度
13. **DTC转型**：直营vs批发的利润结构变化，是否"增收不增利"
14. **RevPAR三因子**：Occ和ADR的联动关系判断周期位置
