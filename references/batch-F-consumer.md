# 消费品牌+零售行业 分析方法论提炼报告

> 基于262篇海豚研究研报（覆盖茅台、瑞幸、携程、华住、中免、安踏、Costco、海底捞、名创、叮咚、青啤、重啤、颐海、韩束、达势、呷哺、特步、李宁、波司登、Lululemon、泡泡玛特、Monster、Meli等），提炼可复用的分析方法论

---

## A. 消费品牌行业分析方法论

### A1. 量价拆解框架：收入=量×价的层层穿透

**核心方法**：将收入增长拆分为"量增"与"价增"两个驱动维度，进一步穿透至各子维度。

**量增维度**：
- **门店数量×店效**：门店数增长又可拆分为"自营新增+加盟新增"，店效可拆分为"客单价×客流量"或"坪效×面积"
- **渠道结构**：线上vs线下、直营vs经销的增速差异
- **品类结构**：核心品类vs新品类的销量贡献变化

**价增维度**：
- **吨价/客单价提升**：直接提价 vs 产品结构升级带来的间接提价
- **品牌溢价**：IP联名、品牌升级带来的溢价能力
- **折扣率变化**：终端折扣收窄=隐性提价

**案例支撑**：
- 安踏2021年营收增速38.9%拆解：安踏主品牌+52.5% vs FILA+25.1%，FILA下半年断崖式下跌从51%跌至6.8%，核心是量（动销）出问题而非价
- 青啤吨价从3,260元/千升提升至3,496元/千升（CAGR 1.9%），驱动力是中高端产品占比从20.6%提升至22.9%，"量降价升"的结构升级逻辑
- 名创优品IP联名产品溢价率30%-100%，带动毛利率从26%提升至37%

**可复用公式**：
```
收入增长 = 同店增长(量×价) + 新店贡献
同店增长 = 客单价增长 × 客流增长
客单价增长 = 提价贡献 + 结构升级贡献
```

### A2. 渠道库存分析：消费品的核心风险指标

**核心方法**：库存不是孤立指标，必须结合渠道模式和产品生命周期综合判断。

**分析框架**：
1. **存货周转天数趋势**：连续2-3个季度上升是预警信号
2. **库存结构**：原材料库存 vs 在途库存 vs 成品库存，成品库存上升更危险
3. **渠道库存**：经销商库存 vs 品牌方库存，经销模式下的渠道库存更隐蔽
4. **库存与增速的背离**：收入增速放缓+库存增速上升=需求端出问题的最危险组合

**案例支撑**：
- 安踏2021年下半年存货周转天数反弹上升，核心原因是FILA动销遇阻，"FILA流水低于预期→库存去化放缓→周转恶化"的传导链
- 运动鞋服行业2012-2015年库存危机的成因：批发模式下品牌商无法感知终端需求，"跑马圈地式开店→需求跟不上→库存积压"的经典路径
- 中免2024年存货减值3.5亿/季（先前仅1-2亿），库存减值加速是基本面恶化的滞后确认指标

**可复用判断规则**：
- DTC/直营模式下，库存上升更可能是主动备货，风险较低
- 经销/批发模式下，库存上升更可能是被动积压，风险较高
- 存货周转天数拐点通常领先利润拐点1-2个季度

### A3. 品牌力/定价权的评估方法

**核心方法**：品牌力的量化评估从四个维度构建。

**评估框架**：
1. **定价能力**：同等产品能否持续定价高于同行？（LULU瑜伽裤定价为阿迪耐克2-3倍，毛利率超同行10pct+）
2. **提价传导能力**：成本上升时能否顺利转嫁？需求弱时能否不降价？
3. **复购率/客户粘性**：复购率越高→品牌力越强→定价权越稳固
4. **溢价来源**：功能溢价vs情感溢价vs社交溢价，三者稳定性递增

**案例支撑**：
- Lululemon的品牌力来源于"极致产品力（面料专利9种）+宗教式社群营销（教育家+品牌大使闭环）"，营销费率明显低于同行却实现高坪效
- 茅台定价权来源于"供给稀缺+先款后货+市场价远高于出厂价"的三重保护，全市场极为罕见
- 名创优品从"平价好物"到"IP联名一哥"的品牌升级路径：通过IP联名将品类认知从"10元店"转向"IP零售"，IP产品占比从0→40%→50%（目标），毛利率从26%→37%

**可复用指标**：
- 毛利率与同行的差距（品牌溢价最直接的量化体现）
- 营销费率与同行的差距（低营销费+高增速=强品牌力）
- 终端折扣率变化趋势（折扣收窄=品牌力增强）

### A4. 消费降级/升级的分析框架

**核心方法**：消费降级和升级不是非此即彼，而是**结构性共存**，关键看"品类—人群—场景"的交叉分析。

**分析维度**：
1. **品类维度**：必选消费韧性 > 可选消费，但高端必选（如茅台）可能比低端可选更脆弱
2. **人群维度**：高净值人群vs中产vs下沉市场，降级影响差异巨大
3. **场景维度**：商务消费vs个人消费，前者对经济周期更敏感

**案例支撑**：
- 茅台从"政务消费占比30-40%"到"大众品质消费+收藏市场"的消费场景转型，与土地财政的兴衰直接相关——"土地财政→商务宴请→茅台需求"的传导链
- 中免"只逛不买"现象：购物客流好于销售额，人均购买件数大幅下降（清理代购影响），但人均消费金额跌幅缩窄至-3%（高端品类上行）
- 瑞幸的"咖啡下乡"策略：9.9元价格带精准切入下沉市场，在消费降级中反而受益——"比星巴克便宜，比速溶好喝"的性价比定位

**可复用判断框架**：
```
消费趋势 = 品类属性（必选/可选） × 价格带（高端/中端/大众） × 渠道（线上/线下/免税）
降级受益标的特征：大众定位+性价比+渠道下沉能力强
升级受益标的特征：品牌力强+复购率高+定价权稳固
```

### A5. 同店增长（SSSG）分析方法

**核心方法**：同店增长是判断成熟连锁品牌经营质量的"灵魂指标"。

**分析框架**：
1. **同店增速的绝对值**：>5%优秀，2-5%正常，<0%需警惕
2. **同店增速的趋势**：连续2-3个季度下滑是最危险的信号
3. **量价拆分**：同店增长=客流量增长×客单价增长，区分是"以量补价"还是"量价齐升"
4. **新店对老店的侵蚀**：新开门店是否分流老店客流（同店蚕食效应）

**案例支撑**：
- 瑞幸2023Q2同店增速21%——"灵魂数据"高增验证了万店狂奔的合理性，"老店同店扩张+新店门店扩张"的双齐飞
- 华住2025Q3 RevPAR同比持平（扭转连续5季度下滑），ADR转正+1%但OCC仍降0.8pct，量价分化表明供需格局边际改善但未全面转好
- 名创优品2025年注重同店销售额增长（纪要），从追求开店数量转向追求店效质量

## B. 餐饮/酒店/服务行业分析方法论

### B1. RevPAR=ADR×Occ分析框架

**核心方法**：RevPAR是酒店业的核心KPI，必须拆分为ADR和Occ两个子指标来理解驱动逻辑。

**分析框架**：
```
RevPAR = ADR × Occ
ADR变动 = 供给竞争 + 品牌升级 + 季节性
Occ变动 = 需求景气度（商务/休闲） + 新店爬坡 + 竞争分流
```

**三种RevPAR变动模式的经济含义**：
1. **ADR↑ Occ↑**：景气度上升期，量价齐升（最佳状态）
2. **ADR↑ Occ↓**：品牌升级/结构调整期，牺牲入住率换均价
3. **ADR↓ Occ↑**：以价换量，竞争加剧期（最需警惕）

**案例支撑**：
- 华住2025Q3：ADR同比+1%（转正），Occ下降0.8pct，属于模式2——结构性提价（新开店重心转向中高端），反映供给放缓+需求回暖
- 华住欧洲市场：RevPAR+6.5%，主要由Occ+4.6%驱动，ADR稳定——国际旅游复苏带动的"以量驱动"
- 华住整体判断："ADR是衡量酒旅行业竞争健康度的重要指标，首次转正表明供需格局趋于平衡"

### B2. 单店模型与UE拆解

**核心方法**：单店UE（Unit Economics）是评估连锁业态扩张质量的底层工具。

**分析框架**：
```
单店利润 = 月店效 - 租金 - 人力 - 水电 - 折旧 - 物料
月店效 = 客单价 × 日均客流 × 30天
盈亏平衡点 = 固定成本 / (客单价 - 变动成本) × 客流
```

**关键指标**：
- 单店回本周期：<12个月优秀，12-18个月正常，>24个月需警惕
- 经营利润率：直营模式15-25%，加盟模式毛利率60%+但需扣除管理成本
- 月店效分布：低效门店占比（如FILA 40%门店月店效低于50万）决定改善空间

**案例支撑**：
- FILA整体月店效接近70万，但40%门店（主要是FILA Kids/FILA FUSION）月店效在50万以下，若改善至70万+，整体店效有望提升30%
- 瑞幸自营门店经营利润率29%（2023Q2），万店规模效应下利润率持续改善
- 华住加盟业务同比增长27.2%（2025Q3），直营业务下滑5.5%——轻资产转型中直营与加盟的利润结构差异

### B3. 加盟vs直营的利润结构差异

**核心方法**：理解加盟和直营的财务模型差异是分析连锁企业转型方向的关键。

**核心对比**：
| 维度 | 直营模式 | 加盟模式 |
|------|---------|---------|
| 收入确认 | 全额确认（含租金、人力等成本） | 仅确认加盟费+分成 |
| 毛利率 | 低（需承担刚性成本） | 高（无租金人力） |
| 经营利润率 | 低（15-25%） | 高（60%+） |
| 扩张速度 | 慢（资本开支大） | 快（占用加盟商资金） |
| 风险承担 | 品牌方承担 | 加盟商分担 |

**案例支撑**：
- 华住轻资产转型：加盟收入占比从40%→47.5%，"加盟模式节省租金人力等刚性成本，毛利率更高"，数字化带来管理费率大幅下降，核心经营利润率创新高29.4%
- 安踏DTC转型：批发经营利润率26%→直营经营利润率单位数（2021年），但长期看"参考FILA品牌收入与盈利质量的快速提升"，直营利润率会逐步恢复
- 名创优品"假加盟真直营"模式：加盟商前期投入60-75万保证金+5-8万品牌费+40-50万装修费，日常运营全部由名创托管，每天获前一日营业额38%——"只出钱不出力"的理财产品式加盟

### B4. 翻台率分析

**核心方法**：翻台率是餐饮业最核心的经营效率指标，但需结合客单价和门店类型综合判断。

**分析要点**：
1. 翻台率的绝对值：>5次/天优秀，3-4次正常，<2次需警惕
2. 翻台率与客单价的跷跷板效应：客单价提升可能压翻台率
3. 不同业态的翻台率基准差异：快餐>火锅>正餐

**案例支撑**：
- 海底捞翻台率从5.0→3.0的变化，是业绩从巅峰回落最直接的量化指标
- 瑞幸不是"翻台率"逻辑而是"杯量×单价"逻辑，门店面积小→坪效极高→不需要高翻台率

## C. 零售/免税行业分析方法论

### C1. 客单价×客流拆解

**核心方法**：零售业收入=客流×转化率×客单价，三者需分层分析。

**案例支撑**：
- 中免2024Q4拆解：购物客流>销售额表现（人均购买件数大幅下降拖累，清理代购影响），但人均消费金额跌幅缩窄至-3%（高客单价奢侈品上行）
- 名创优品单店模型：月店效=日均客流×客单价×30天，IP联名提升客单价是核心驱动力
- Costco的会员制模式：会员费贡献利润主体，商品本身低毛利，本质是"用商品引流，用会员费赚钱"

### C2. 线上vs线下渠道分析

**核心方法**：不同渠道的增长贡献、利润贡献和战略定位需分开评估。

**分析框架**：
1. 渠道增速贡献拆解：线上增速 vs 线下增速 vs 整体增速
2. 渠道利润差异：线下直营毛利率最高但费用率也高
3. 渠道战略定位：线上做品牌+引流，线下做体验+转化

**案例支撑**：
- 中免有税销售（线上为主）同比-26% vs 免税销售-16%，有税业务疫情期间"救火"现在成为"罪魁祸首"
- 安踏线上占比29%，较2020年增长50%，在高基数下仍实现强劲增长
- Lululemon DTC渠道（线上）2020年收入增101%，占总营收52%（2019年仅29%），线下直营门店全直营保证价格管控

### C3. 会员/复购率分析

**核心方法**：会员体系是零售业复购率和客户终身价值（LTV）的核心抓手。

**案例支撑**：
- Costco会员续费率超90%，会员费贡献净利润主体——"低毛利商品+高续费会员"的飞轮效应
- Lululemon社群营销本质是高复购体系：教育家（KOC）+品牌大使（KOL）构建"品牌-门店-教育家-大使-用户"垂直营销闭环
- 瑞幸2023Q2活跃买家4300万+（同比+100%），6月累计买家1.7亿——"万店齐飞=对现饮咖啡心智的占领"

## D. 服装/运动品牌分析方法论

### D1. 库存/折扣率分析

**核心方法**：库存和折扣率是运动品牌最核心的经营质量指标，两者互为因果。

**分析框架**：
```
库存压力 → 被动加大折扣 → 毛利率受损 → 品牌力损伤
库存健康 → 主动控制折扣 → 毛利率改善 → 品牌力增强
```

**判断指标**：
- 存货周转天数趋势（同比/环比）
- 终端折扣率变化（渠道调研）
- 库销比（库存/近3个月销售）

**案例支撑**：
- 安踏2021全年各品牌零售终端折扣同比均收窄→毛利率提升3.4pct至61.6%
- Lululemon全直营模式=强管控折扣和库存水平，维护品牌高端形象，拉高整体毛利率
- 运动鞋服行业库存危机（2012-2015）的根源：批发模式下品牌商无法感知终端需求

### D2. DTC vs 经销渠道转型

**核心方法**：DTC转型是近年来运动品牌最大的结构性变化，需要从"短期阵痛+长期收益"两个时间维度评估。

**短期影响（1-2年）**：
- 回购经销商库存→存货周转天数上升
- 直营门店运营成本→经营利润率短期下降
- 门店调整→部分低效店关闭

**长期收益（3年+）**：
- 批发→零售模式→毛利率大幅提升
- 直接触达消费者→数据驱动精准运营
- 控制终端折扣→品牌力增强

**案例支撑**：
- 安踏DTC转型：批发经营利润率26%→直营经营利润率单位数（短期），但FILA直营模式验证了长期利润率可恢复至20%+
- 安踏首批DTC转型涉及3500家门店，60%直营+40%加盟标准运营，投入约20亿元（80-90%与库存回购相关）
- Lululemon纯DTC模式：92%收入来自直营（含线下），品牌力极强→高溢价→高复购→高ROE

### D3. 品牌矩阵分析

**核心方法**：多品牌集团需要分析每个品牌的定位差异、生命周期阶段和协同效应。

**分析框架**：
```
品牌矩阵评估 = 定位差异化 × 生命周期阶段 × 品牌间协同
定位差异化：大众/中端/高端 × 运动/时尚/户外
生命周期：导入期/成长期/成熟期/衰退期
协同效应：供应链共享 × 渠道复用 × 管理输出
```

**案例支撑**：
- 安踏"单聚焦、多品牌、全渠道"：安踏主品牌（大众）+FILA（时尚中高端）+迪桑特/可隆/Amer（户外高端），FILA成功经验能否复制到新品牌是核心投资逻辑
- FILA品牌裂变：FILA→FILA Kids→FILA FUSION，从单一消费群体到家庭消费群体全覆盖
- 青啤品牌分层：青岛品牌主攻中高端（吨价4,446元），崂山品牌守低端，"主品牌冲锋+副品牌守阵地"

## E. 估值方法

### E1. 消费品牌的PE/PEG估值

**核心方法**：消费品牌估值的核心不是PE绝对值，而是PE与增速匹配度和确定性溢价。

**估值框架**：
1. **PE绝对值**：消费龙头PE通常20-35x为合理区间
2. **PEG思维**：PE/增速<1.5为合理，但需叠加确定性调整
3. **确定性溢价**：增速相同但确定性更高的企业应给更高PE
4. **估值锚**：10年期PE均值是重要参考（中免30x接近10年期均值）

**案例支撑**：
- 安踏2021年PE从80x高位下杀至26x（港股流动性危机），30-35x为合理中枢
- 中免2024年30x PE匹配"营收利润双下滑"的业绩"显然不算便宜"，但20x PE可作为估值铁底
- 瑞幸扩张期25-30x PE为合理状态，2023全年35-40亿净利润预期→合理估值120亿美金+

### E2. 确定性溢价的DCF验证

**核心方法**：用DCF思维理解确定性溢价——折现率r越低，企业内在价值越高（V=C/r-g）。

**核心公式**：
```
企业价值 = C / (r - g)
r = 无风险利率 + 确定性风险溢价
确定性越高 → r越低 → 估值越高
```

**案例支撑**：
- 巴菲特估值逻辑：茅台折现率7%→33倍估值，五粮液折现率8%→25倍估值（假设永续增长率相同4%）
- "15倍PE+7%增长"≈"10倍PE无增长"（十年回本等价），这是巴菲特愿意为成长付出的溢价
- 茅台的确定性来源：①产量可预测 ②提价能力极强（直接/间接） ③产品尽产尽销 ④市场价远高于出厂价——"世界的变化几乎与我无关"

### E3. 品牌力的定量化评估

**核心方法**：品牌力无法直接量化，但可以通过代理指标近似评估。

**代理指标体系**：
1. **毛利率与同行差距**：品牌力最直接的财务体现（LULU毛利率超同行10pct+）
2. **营销费率与增速的组合**：低费率+高增速=品牌力驱动
3. **终端折扣率**：折扣收窄=品牌力增强
4. **坪效/店效**：LULU北美服装行业最高坪效，仅次于苹果和蒂芙尼
5. **ROE**：LULU常年15%+，"标准的巴菲特式好公司"

## F. 共性方法论

### F1. 预期差含金量判断案例

**案例1：瑞幸同店增速超预期（高含金量）**
- 市场预期同店增速10%以内，实际21%
- 含金量高：因为①万店规模下仍高增=天花板更高②经营利润率同时创新高=不是以价换量
- 结论：瑞幸"EPS+估值"双击年

**案例2：中免业绩持续低于预期（预期差持续为负）**
- 市场预期25年利润60亿，实际24年利润仅42.7亿且仍在下滑
- 含金量判断：定价隐含"25年业绩一定触底反弹"并不够保险
- 结论：低含金量预期差，安全边际不足

**案例3：华住RevPAR环比修复（中等含金量）**
- 市场关注RevPAR是否企稳，Q3首次持平超预期
- 含金量中等：①供需格局确实在改善②但OCC仍在下降③ADR转正部分因结构升级
- 结论：边际改善确认，但非趋势性反转

### F2. 三层利润穿透案例

**案例：安踏体育利润穿透**
```
第一层：GAAP归母净利润77.2亿（含Amer亏损）
  ↓ 剔除
第二层：分品牌经营利润
  - 安踏品牌经营利润率21.4%（DTC转型拖累，批发26%→直营单位数）
  - FILA经营利润率24.5%（下滑1.3pct，动销遇阻）
  ↓ 剔除
第三层：核心经营利润趋势
  - 毛利率提升3.4pct（折扣收窄+DTC+自有产能降本）
  - 费用率上升（冬奥营销+DTC员工增加）
  → 毛利改善被费用侵蚀，净利率仅提升1pct
```

**案例：中国中免利润穿透**
```
第一层：归母净利润3.5亿/季（极低）
  ↓ 剔除
第二层：毛销差15.7亿（环比持平）
  → 毛利率下滑3.5pct被营销费率下降抵消
  ↓ 剔除
第三层：业务结构利润
  → 免税毛利率39.5%稳定（"成本+目标毛利率"定价策略）
  → 有税毛利率腰斩至8.9%（从17.4%）→主要拖累来源
  → 核心问题不是免税不行，而是有税业务"两头拖累"
```

## G. 消费行业独有的分析框架总结

### G1. 啤酒行业利润池分析框架

**核心概念**：啤酒企业的利润来自"利润池市场"，而非全国均匀分布。

**利润池形成条件**：
1. 市场容量足够大（>100万千升/年）
2. 区域市占率足够高（>40%，最好60%+）
3. 产品结构合理（中高端占比提升中）

**案例**：青啤山东市场（规模300万千升+，市占率75%+）贡献主要利润，而华润天津市场虽市占率40%+但规模仅30万千升，难以形成利润支撑。

### G2. IP零售的"重赔率轻胜率"模型

**核心逻辑**：IP联名生意的本质不是"每个IP都赚钱"，而是"少量爆款覆盖大量亏损"。

**分析框架**：
- 胜率：名创从2019年大规模IP联名以来，真正盈利的IP占比不足5%
- 赔率：5%的爆款IP可以弥补其他IP的亏损+强化"名创=IP联名"消费者心智
- 速度：从捕捉热门IP到上新<3个月（同行>6个月），背后是供应链效率

### G3. 连锁业态的"老店同店+新店贡献"双轮分析

**核心框架**：
```
收入增长 = 老店同店增长 + 新店净增贡献
健康状态 = 老店同店>5% + 新店回本周期<18个月
危险信号 = 老店同店<0% 且 新店仍在快速扩张
```

**案例**：瑞幸2023Q2自营门店收入+85%，其中"成熟门店群体拉动了50个增长点"——老店同店增长+新店扩张的"双齐飞"。

### G4. 消费股阿尔法来源四要素

1. **行业空间大**：万亿级赛道（预制菜、咖啡、运动鞋服）
2. **产品通用性强，有规模效应**：通用性越强→规模效应越大→大市值可能性越高
3. **有一定竞争壁垒**：品牌力/渠道力/供应链力
4. **产业链有议价权**：上下游中有一方竞争格局分散

**核心结论**：消费股主要赚个股阿尔法的钱，而非行业贝塔。龙头集中度提升+品类拓展是主要逻辑，而非行业整体增速。
