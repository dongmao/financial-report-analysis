## 一、硬科技的商业本质

```
硬科技公司 ≠ 互联网公司
核心差异：
├── 盈利能力可见性高（订单/产能 = 可预测）
├── 周期性强（半导体/电池有明显库存周期）
├── 资本开支大（折旧摊销影响利润）
├── 技术路线决定生死（选错=淘汰）
└── 政策/地缘政治影响大（中国vs美国）
```

### 硬科技四维分析框架

```
第一维：技术路线 — 在哪里？
├── 行业技术处于哪个节点？（导入/成长/成熟/衰退）
├── 公司的技术储备是否在正确方向上？
└── 技术路线变化会带来什么颠覆？

第二维：产能供给 — 供给侧分析
├── 产能扩张节奏 vs 需求增速
├── 产能利用率 → 价格压力
└── 技术升级需要资本开支周期

第三维：需求与政策 — 市场侧分析
├── 终端需求增速（EV渗透率/AI应用/能源转型）
├── 政策支持力度（补贴/国产替代/关税）
└── 竞争格局（CR3/CR5集中度）

第四维：财务健康 — 防御性指标
├── 毛利率趋势（成本转嫁能力）
├── 现金流质量（资本开支强度）
└── 资产负债表（债务结构）
```

## 二、半导体：核心指标体系

### 2.1 半导体周期四阶段识别

```
【半导体周期分析】

Stage 1 → 库存去化期（股价往往先于基本面见底）
├── 需求下滑 + 产能刚投产 → 供过于求
├── 厂商降价去库存 → 毛利率承压
└── 指标：ISSR（Integrated Circuit/Silicon Ratio）< 1

Stage 2 → 补库存周期启动
├── AI/新能源等新需求涌现
├── 订单回升 → 产能利用率提升
└── 指标：Foundry产能利用率 > 85%

Stage 3 → 超级周期
├── 所有产能被预订 + 涨价
├── 毛利率显著扩张
└── 指标：SOX指数 vs 费城半导体指数

Stage 4 → 产能过剩
├── 新产能集中释放
├── 价格战开始
└── 指标：平均交付周期缩短
```

### 2.2 半导体公司关键指标

**📊 设备/制造（台积电/三星/中芯国际）**
| 指标 | 含义 | 关注方式 |
|------|------|---------|
| **产能利用率** | 产能负荷 | >85%=紧张；<70%=过剩信号 |
| **先进制程占比** | 7nm/5nm/3nm收入占比 | 越先进=毛利率越高 |
| **资本开支** | 扩产强度 | 周期底部扩张=逆势投资 |
| **晶圆ASP** | 单位售价趋势 | 涨价=供需紧张 |
| **NPI（新工艺导入）** | 新制程进展 | 良率提升曲线 |

**💾 芯片设计（英伟达/AMD/高通）**
| 指标 | 含义 | 关注方式 |
|------|------|---------|
| **数据中心收入占比** | AI驱动程度 | 占比↑=估值重估 |
| **库存水位** | 渠道库存 | 去化周期位置 |
| **产品组合ASP** | 高端vs低端占比 | 产品结构影响毛利率 |

## 三、新能源汽车与电池：核心指标

### 3.1 EV价格战评估框架

```
【EV竞争格局分析】

1. 价格战阶段判断
   ├── 导入期（渗透率<10%）：不打价格战，抢份额
   ├── 成长早期（10-30%）：开始价格竞争
   ├── 成长中后期（30-50%）：价格战最激烈
   └── 成熟期（>50%）：价格战缓和，剩者为王

2. 各方优劣势
   ├── 特斯拉：品牌+自动驾驶，但成本高
   ├── 比亚迪：垂直整合+成本控制，刀片电池
   ├── 新势力：产品定义+用户运营，但亏损大
   └── 传统车企：渠道+制造，但转型慢

3. 胜负关键指标
   ├── 单车毛利（正值=可持续）
   ├── 研发费用率（决定未来竞争力）
   └── 自由现金流（能否撑过价格战）
```

### 3.2 电池成本传导链条

```
【电池产业链分析】

上游：锂/钴/镍 → 电池厂 → 整车厂 → 消费者

成本压力传导：
├── 碳酸锂涨价 → 电池厂成本↑ → 整车厂被迫提价
├── 碳酸锂跌价 → 电池厂成本↓ → 整车厂有降价空间
└── 电池厂利润率 = 技术降本 - 原材料波动

关键指标：
├── 碳酸锂价格（每周跟踪）
├── 电池能量密度（Wh/kg）
├── 循环寿命（衰减曲线）
└── 产能利用率（供过于求/不足）
```

### 3.3 EV与电池公司关键指标

**🚗 整车（比亚迪/理想/小鹏/特斯拉）**
| 指标 | 含义 | 关注方式 |
|------|------|---------|
| **交付量及增速** | 市场份额变化 | 同比+环比双维度 |
| **单车毛利** | 定价+成本控制 | 能否持续为正 |
| **毛利率** | 整体盈利质量 | 价格战下趋势 |
| **研发费用率** | 未来竞争力 | 智能化投入 |
| **Free Cash Flow** | 能否持续经营 | 价格战生存关键 |
| **门店数量/城市覆盖** | 渠道扩张 | 下沉市场渗透 |

**🔋 电池（宁德时代/亿纬锂能/国轩）**
| 指标 | 含义 | 关注方式 |
|------|------|---------|
| **出货量及增速** | 动力/储能分别看 | 全球市占率 |
| **产能利用率** | 供需平衡 | >80%=紧张 |
| **单Wh成本** | 成本竞争力 | 每年下降10-15% |
| **毛利率** | 定价权 | 原材料涨价传导 |
| **存货周转天数** | 库存周期位置 | 供过于求信号 |

## 五、AI基建/电力/数据中心分析

### 5.1 AI Capex传导链

```
【AI Capex→芯片设计→代工→设备→材料的传导链】

云厂商AI Capex ↑ → AI芯片设计需求 ↑ → 代工订单 ↑ → 设备采购 ↑ → 材料需求 ↑

传导链不是均匀的：
├── 某些环节可能因产能/技术/战略原因出现断点
├── ASML案例：AI需求尚未传导至光刻系统（台积电重心在先进封装）
├── 各环节时滞不同：设计→代工较快（1季度），代工→设备较慢（2-3季度）
└── 产业链位置决定受益程度：中间环节（戴尔）面临被ODM绕开的风险
```

### 5.2 AI电力/数据中心指标

| 指标 | 含义 | 关注方式 |

| **AI算力（GW）** | 数据中心电力需求 | Meta 2026年新增4GW，英伟达约500亿/GW部署成本 |

## 六、半导体深度分析补充

### 6.1 单晶圆毛利微观拆解法

```
【台积电毛利拆解模型】

收入 = 晶圆出货量 × 单晶圆收入（等效12寸）
毛利 = 单晶圆收入 - 单位固定成本 - 单位可变成本
毛利率 = 毛利 / 单晶圆收入

拆解步骤：
1. 计算单晶圆收入变化（价格端）
2. 计算单位固定成本变化（折旧摊销/出货量）
3. 计算单位可变成本变化（制造费用）
4. 量化各因素对毛利率的独立贡献

案例（台积电2023Q1）：
├── 单晶圆收入：5181美元，环比-202（价格端影响47%）
├── 固定成本：1124美元，环比+198（成本端影响46%）→ 产能利用率↓是主因
├── 可变成本：1139美元，环比+31（成本端影响7%）
└── 单片毛利下滑431美元：价格端202(47%) vs 成本端229(53%)

⚠️ 核心洞察：产能利用率下滑时，固定成本摊薄是毛利率下滑的最大杀手
此模型适用于所有重资产制造业（晶圆代工、电池、面板等）
```

### 6.2 ASIC vs GPU商业模式差异

| 维度 | ASIC（定制芯片） | GPU（通用芯片） |
|------|-----------------|----------------|
| **客户关系** | 大厂定制（谷歌/亚马逊） | 标准化产品卖给全市场 |
| **议价权** | 客户议价权强→毛利率低 | 供应商议价权强→毛利率高 |
| **增长逻辑** | 只要大厂Capex继续增长→大逻辑持续 | 市场份额+产品迭代 |
| **风险** | 客户集中度高，单客户波动影响大 | 周期性库存调整 |
| **案例** | 博通AI收入三大客户+第四客户超100亿订单 | 英伟达GPU市场份额80%+ |

### 6.3 AI需求的结构性vs周期性判断

```
关键判断：公司业务中AI结构性增长能否覆盖传统周期性下滑？

当结构性业务占比<30%时 → 公司整体仍随周期波动
案例美光：AI/HBM量价齐升（结构性），但手机/汽车库存调整（周期性）→AI再火也填不平"周期坑"

案例应用材料AMAT：AI芯片可复用手机产线→新增Capex需求有限→AMAT在AI周期中景气度不如预期
案例戴尔：大厂Capex提升≠戴尔直接受益（ODM Direct模式绕过中间商）
```

## 七、新能源车深度分析补充

### 7.1 量利关系分析框架

```
【新能源车的"量利关系"三阶段】

阶段一：量增利降
├── 渗透率10-30%，价格战开始
├── 销量飙升但单车毛利下降
├── 典型：2023-2025年中国新能源车市场
└── 关键判断：规模效应能否覆盖价格下降

阶段二：量利齐升
├── 渗透率30-50%，龙头胜出
├── 规模效应显现，单车成本下降>价格下降
├── 典型：比亚迪2023-2024
└── 关键判断：能否维持领先的成本优势

阶段三：量稳利升
├── 渗透率>50%，格局稳定
├── 增速放缓但利润率改善
├── 典型：特斯拉（成熟市场）
└── 关键判断：智能化/服务能否打开第二曲线
```

### 7.2 混动/增程 vs 纯电的产品策略分析

```
混动/增程的优势：
├── 无里程焦虑 → 覆盖更广用户群
├── 电池容量小 → 成本更低，毛利更高
├── 典型：理想增程、比亚迪DM-i

纯电的优势：
├── 技术路线更先进（终局）
├── 智能化程度更高
├── 典型：特斯拉、小鹏

关键判断：混动是过渡还是长期并存？
├── 充电基础设施完善度决定纯电渗透速度
├── 电池成本下降速度决定纯电vs混动的价格差
└── 中国市场：混动在10-20万价格带仍有2-3年优势窗口
```

## 八、分析要点清单

1. **判断技术路线**：公司是否在正确的技术方向上？
2. **跟踪周期位置**：供过于求 vs 供不应求？
3. **政策环境评估**：补贴/关税/出口管制的影响？
4. **成本转嫁能力**：原材料涨价能否传导至下游？
5. **资本开支节奏**：逆势扩张还是顺周期？
6. **竞争格局演变**：CR3/CR5在集中还是分散？
7. **资产负债表健康度**：债务结构能否撑过下行周期？
