# 财务数据完整性检查清单

> 在开始任何深度分析之前，先确认数据是否完整、准确、一致。
> 
> **使用时机**：Phase 2（数据采集与清洗）阶段

---

## 一、数据完整性自检

### 1.1 必备数据项（分析前必须全部获取）

#### 利润表（至少4个季度）

- [ ] 营业总收入（单季 + TTM）
- [ ] 营业成本
- [ ] 毛利 = 收入 - 成本
- [ ] 毛利率 = 毛利 / 收入
- [ ] 销售费用 / 管理费用 / 研发费用
- [ ] 经营利润
- [ ] 净利润（GAAP + Non-GAAP/调整后）
- [ ] EPS（基本 + 稀释 + 调整后）

#### 资产负债表（最近一期）

- [ ] 货币资金 + 短期投资
- [ ] 应收账款及票据
- [ ] 存货
- [ ] 总资产 / 总负债 / 净资产
- [ ] 商誉
- [ ] 短期有息负债 / 长期有息负债

#### 现金流量表（至少4个季度）

- [ ] 经营活动现金流净额(OCF)
- [ ] 投资活动现金流净额
- [ ] 筹资活动现金流净额
- [ ] 资本性支出(Capex)
- [ ] 自由现金流(FCF = OCF - Capex)

### 1.2 因行业而异的补充运营数据

| 行业 | 补充必备数据 |
|------|------------|
| 互联网平台 | GMV、DAU/MAU、付费用户数、ARPU |
| 广告业务 | eCPM、广告加载率、广告主数量 |
| 电商 | GMV、AOV(客单价)、订单量、Take rate |
| 本地生活 | GTV、UE模型数据（单均收入-履费-补贴）|
| 游戏 | 流水 vs 确认收入、Pipeline、付费用户数 |
| 消费零售 | 同店销售SSS、门店数、客单价AOV |
| 消费餐饮 | 同店SSS、翻台率、门店回本周期 |
| 新能源车 | 交付量、单车毛利、在手订单backlog |
| 电池 | 出货量(GWh)、单价、产能利用率 |
| 半导体 | 产能利用率、ASP、Capex、存货周转天数 |

## 二、数据一致性校验

### 2.1 内部一致性检查

```
检查1：毛利率计算一致性 → expected vs reported 差异 > 1pp 需调查
检查2：费用项加总 = 收入 - 经营成本 - 毛利 → 差异过大说明有未披露项目
检查3：资产负债表平衡 → 总资产 = 总负债 + 净权益
检查4：现金流量勾稽 → OCF+ICF+FCF ≈ 货币资金变动
```

### 2.2 时间序列一致性

- [ ] 各季度会计期间一致？（自然季 vs 财年季）
- [ ] 货币单位统一？（同一币种和单位）
- [ ] 会计准则一致？（GAAP vs IFRS vs CAS）
- [ ] 合并范围一致？（有无业务剥离/并购导致口径变化）
- [ ] 数据来源标注完整？

## 三、常见数据问题处理指南

| 问题类型 | 表现 | 处理方法 |
|---------|------|---------|
| **数据缺失** | 某季度的某个指标为空 | 用前后季均值填充（需标注）或排除该季度 |
| **口径变更** | 公司调整了收入确认政策或分部划分 | 用新口径重述历史数据或明确区分前后口径 |
| **一次性重组** | 业务出售/收购导致不可比 | 分别分析"持续经营"和"终止经营" |
| **汇率波动** | 跨国公司收入受汇率影响大 | 提供"固定汇率增速"和"实际增速"两组 |
| **非经常性损益** | 大额资产处置/减值/汇兑 | 同时提供"含非经常性"和"扣非后"两组 |

## 四、数据质量自评

```
### 完整性：__/10
- 利润表核心字段齐全 (2分)
- 资产负债表核心字段齐全 (2分)
- 现金流量表核心字段齐全 (2分)
- 运营指标获取充分 (2分)
- 有至少4个季度历史数据 (2分)

### 准确性：__/10
- 数据来源可信 (3分)
- 已做内部一致性检验 (3分)
- 已做跨源交叉验证 (2分)
- 异常值已标记调查 (2分)

### 时效性：__/10
- 使用最新一期财报 (5分)
- 距财报发布≤2个月 (3分)
- 已获取最新管理层指引 (2分)

总分 ≥ 25/30: ✅ 可进入深度分析
总分 18-24/30: 🟡 基本可用，部分缺失需在分析中说明
总分 < 18/30: 🔴 数据不足，建议先补充数据
```
