# 腾讯+阿里研报方法论提炼

## 概述
本报告基于海豚研究（长桥海豚投研）关于腾讯控股和阿里巴巴的约158篇研报，实际精读了10篇核心财报分析文章（覆盖2020-2025年），重点提取了可复用的分析方法论。

覆盖公司：腾讯控股（0700.HK）、阿里巴巴（BABA/9988.HK）、腾讯音乐（TME）
覆盖时期：2020年-2025年8月，横跨互联网反垄断、疫情、降本增效、AI转型四大周期

**整体方法论特色**：海豚投研的核心特色是"三层穿透+预期差驱动"——先建立市场一致预期基准，再逐层穿透业务线找到预期差来源，最后判断预期差的含金量（核心经营利润 vs 一次性项目）。叙事风格鲜明，标题直击核心矛盾，分析层层递进。

---

## 一、分析框架特色

### 1.1 收入拆解

**A. 腾讯四柱收入拆解法**
海豚投研将腾讯收入拆为四大支柱：游戏、广告、金科与企服、数字内容，每个支柱内部再行二级拆解：

- **游戏**：本土 vs 海外 → 手游 vs 端游 → 新游增量 vs 老游衰减 → 递延收入推算流水
- **广告**：社交广告 vs 媒体广告 → 视频号增量 vs 传统存量 → 加载率提升 vs eCPM涨价 vs 行业大盘
- **金科与企服**：支付 vs 云业务 → 央行备付金倒推支付增速 → 剔除视频号佣金推算云业务
- **数字内容**：付费用户×ARPPU → 付费率提升（非忠诚用户流失后的结构性改善）

案例：《360度无死角拆腾讯》系列，每个季度按此框架逐项拆解，形成可复用的分析模板。

**B. 阿里分层收入拆解法**
阿里采用"核心平台零售 + 重资产零售 + 新业务"三层结构：

- **平台零售（淘宝天猫）**：客户管理收入（广告+佣金）→ Take rate × GMV → 剥离出GMV增速和变现率变动
- **重资产零售（盒马/饿了么/菜鸟/Lazada等）**：收入增速 + 亏损率 → 判断投入效率
- **新故事线（云/菜鸟/大文娱）**：收入增速 + 亏损收窄进度 → 判断独立造血能力

案例：《细拆阿里》中，将核心电商利润拆为"平台利润"和"重资产业务亏损"，清晰展示了"边线炮火收回，转投主战场"的战略再平衡逻辑。

### 1.2 利润归因

**核心经营利润 vs Non-IFRS净利润的三层穿透**

海豚投研独创性地强调"核心主业的经营利润"指标，而非直接看Non-IFRS归母净利润。原因：

1. Non-IFRS净利润包含分占联营公司盈利波动（如拼多多季度预估修正）
2. Non-IFRS净利润受一次性所得税调整影响（如腾讯Q1 2023一次性递延税50亿）
3. 核心经营利润（=毛利-经营费用）更真实反映主业经营改善

案例：《腾讯没有惊喜？股王黄金质地藏不住》中，核心经营利润同比增长63%，而Non-IFRS净利润因税费异常仅增长28%。海豚明确指出"如果剔除税费影响，税前盈利以及核心主业的经营利润情况，则是妥妥超预期"。

**毛利率变动的归因方法论**

海豚投研对毛利率变动的归因极为精细，至少从三个维度拆解：

1. **收入结构效应**：高毛利业务占比提升（如游戏+广告占比提高拉高综合毛利率）
2. **成本结构效应**：带宽成本下降、服务器折旧优化、内容成本压缩
3. **业务自身改善**：云业务减少低毛利分包、广告减少联盟分成、游戏减少外部渠道分发

案例：《"中年"腾讯》中，金科业务毛利率创新高的归因："除了云业务本身毛利率改善外，还有视频号电商佣金、消费贷等高毛利业务扩张的带动"。

**费用率分析的颗粒度**

海豚投研将费用率分析做到了极致颗粒度：
- 销售费用 → 拆出推广支出 vs 销售人员薪酬
- 管理费用 → 拆出雇员福利（总人数×人均薪酬）
- 研发费用 → 拆出研发人员薪酬 vs AI服务器摊销成本
- 特别关注：股权激励发放季（Q2）的薪酬异常

案例：《360度无死角拆腾讯》中，"虽然二季度是股权激励发放季，但集团不仅员工总人数下降，人均薪酬也略有降低"——这种季节性+结构性的交叉分析极具洞察力。

### 1.3 现金流分析

**自由现金流的计算验证法**

《腾讯的自由现金流怎么算》一文展示了完整的方法论：

1. 从净利润出发，用间接法调节至经营活动现金流
2. 识别四大类调节项目：非现金费用、非经营损益、经营性应收应付变动
3. 用"折旧+摊销"替代维持性资本开支
4. 验证结论：Non-IFRS净利润 ≈ 自由现金流（2010-2022年累计7728亿 vs 7895亿）

**核心洞察**：腾讯的净利润含金量高——2020年之前经营现金流/净利润倍数平均1.45倍，即便考虑2021-2022年分红京东美团的影响，整体仍达1.13倍。

**股份酬金的穿透分析**
- 以权益结算的股份酬金：计入管理费用影响利润，但在现金流量表属筹资活动（需加回经营现金流）
- 以现金结算的股份酬金：属经营活动现金流，直接支付
- 2010-2022年累计股份酬金1233亿，其中权益结算955亿——这一项是评估腾讯真实盈利能力的关键调节项

### 1.4 估值方法选择逻辑

海豚投研对腾讯的估值框架：

1. **主营业务PE估值**：Non-IFRS净利润 × 合理PE（15-20x为中性区间）
2. **投资资产加回**：联营/合营资产按80%折价计入（约7000亿港元）
3. **净现金加回**：现金+存款-有息债务（约400亿港元）
4. **最终企业价值 = 主营PE估值 + 投资资产折价 + 净现金**

案例：《"中年"腾讯》中，"3.07万亿港元市值对应今年Non-IFRS净利润19倍，尚属中位水平。而关键在于这只有主营业务价值，还有近7000亿港元的股权资产价值和近400亿港元净现金未被合理定价。"

对阿里的估值则更注重：
- **平台零售take rate的长期趋势**（从70%利润率到65%的新常态）
- **云业务的独立估值故事**
- **分拆后各业务线的SOTP估值**

## 二、预期差分析

### 2.1 建立市场预期基准

海豚投研的预期基准建立方法：

1. **彭博一致预期**作为锚点
2. **管理层指引**作为下限参考（"管理层给的指引相对保守"是常见表述）
3. **核心投行预期**作为细分参考（"部分核心投行预期直接拉到下滑近30%"）
4. **自己调研**作为增量信息源

### 2.2 识别预期差

**海豚投研的预期差识别矩阵**：

| 预期差类型 | 识别方法 | 案例 |
|---|---|---|
| 收入端预期差 | 分业务对比一致预期 | 腾讯Q2 2022：广告"超预期"（实际-17% vs 预期-26%），金科"不及预期" |
| 利润端预期差 | 核心经营利润 vs Non-IFRS | 腾讯Q1 2023：核心经营利润+63% vs Non-IFRS +28%（税费异常） |
| 结构性预期差 | 剔除一次性因素后 | 腾讯Q1 2024：广告+26%超预期，但剔除视频号后传统广告仅高个位数 |
| 联营公司预期差 | 分占盈利的季度预估修正 | 腾讯Q2 2025：拼多多Q1利润miss，Q2多退少补导致分占盈利同比-42% |

### 2.3 预期差的含金量判断

海豚投研明确区分"实"的预期差和"虚"的预期差：

**"实"的预期差（高含金量）**：
- 核心业务毛利率超预期 → 可持续的盈利能力改善
- 降本增效带来的费用率下降 → 但需区分一次性裁员效应和持续性提效
- 视频号商业化加速 → 新增量的持续性较强

**"虚"的预期差（低含金量）**：
- 一次性税费调整（如Q1 2023的50亿递延税）
- 联营公司预估修正（如拼多多利润的季度调节）
- 投资处置收益（如减持京东的780亿）
- 疫情等一次性因素（如封控带来的线上预算转移）

**"中"含金量预期差**：
- 递延收入的环比变动 → 前瞻性指标但包含非游戏项
- 行业性eCPM涨价 → 外部因素，不可持续
- 联盟广告分成的减少 → 结构性改善但有上限

### 2.4 具体预期差案例

**案例1：腾讯Q2 2022广告超预期**
- 市场预期：广告下滑25-30%（教育监管+宏观低迷+字节竞争）
- 实际：下滑仅17%
- 预期差来源：①线下广告预算向线上转移 ②腾讯系渠道流量流失趋势放缓
- 含金量判断：中等——部分为一次性因素（线下转线上），部分为结构性改善

**案例2：腾讯Q1 2024利润加速**
- 市场预期：Non-IFRS净利润高基数下增速放缓
- 实际：增长55%，显著超预期
- 预期差来源：①广告（视频号）超预期 ②高毛利业务占比提升 ③人员缩编
- 含金量判断：高——核心经营利润的改善，非一次性因素

**案例3：阿里FY2021Q2平台零售利润率下滑**
- 市场预期：核心电商利润率保持70%左右
- 实际：利润率降至63.7%
- 预期差来源：阿里将边线战场炮火收回，转投主战场补贴
- 含金量判断：结构性变化——65%可能成为新常态，不是短期波动

## 三、产业链/竞争分析

### 3.1 产业链传导分析

**互联网广告的产业链传导**
海豚投研展示了完整的广告产业链传导逻辑：

宏观消费 → 广告主预算 → 渠道竞争格局 → 平台广告收入

具体传导链条：
1. 终端消费疲软 → 广告主缩减预算
2. 电商竞争加剧（抖快vs淘系）→ 传统平台对流量需求达到顶峰
3. 非直接竞争的渠道（腾讯）成为"隔岸观火"的受益者
4. 商家视微信为"私域流量最后聚集地"→ 主动增加投放

案例：《"中年"腾讯》中，"抖快成长太迅速，电商竞争加剧白热化，传统平台对流量的需求达到了顶峰，因此拥有第一流量规模但又不是直接竞争的腾讯渠道，成为了各家争相投放的必选。"

**支付的产业链传导**
社零数据 → 央行备付金规模 → 第三方支付增速 → 微信支付收入

海豚投研用央行备付金作为行业先行指标，倒推支付业务增速，再剔除支付推算云业务增速——这是非常巧妙的交叉验证方法。

### 3.2 竞品对比方法

**时长份额追踪法**
持续追踪QuestMobile的腾讯系 vs 字节系app用户时长份额变化，判断竞争格局演变。

关键洞察：腾讯系时长份额虽然在缓慢下降，但已逐渐趋于稳定——这是"竞争格局触底"的信号。

**云业务对标法**
将阿里云增速与Azure对比，判断云业务的全球竞争力：
- 疫情前：阿里云增速稍高于Azure
- 疫情后：阿里云明显甩开Azure
- 放缓期：阿里云增速回落至与Azure一致

**游戏跑赢/跑输行业法**
将腾讯游戏流水增速与伽马数据行业增速对比：
- 跑赢行业：产品周期上行期
- 跑输行业：老游衰退+新游空窗期
- 关键判断：递延收入环比变动是前瞻性指标

### 3.3 竞争格局变化评估

**电商竞争格局的"战争再平衡"模型**
海豚投研对阿里的竞争分析建立了一个"主战场vs边线战场"框架：

1. 阿里面临拼多多、京东在核心电商的进攻
2. 资源有限，必须做"战争再平衡"——收缩边线（大文娱减亏），加码主战场（淘宝补贴）
3. 直接后果：核心零售利润率从70%降至65%
4. 海豚判断：65%可能成为新常态，需要在估值中反映

## 四、叙事技巧

### 4.1 标题定调方式

海豚投研的标题极具辨识度，采用"核心矛盾+态度判断"的结构：

| 类型 | 标题示例 | 方法论 |
|---|---|---|
| 预期差型 | "360度无死角拆腾讯：真有那么糟糕吗？" | 先承认市场悲观，再反转 |
| 周期定位型 | ""中年"腾讯：跑不动了只能省省省" | 用人生阶段比喻业务周期 |
| 转折确认型 | "腾讯：视频号变身摇钱树，股王优雅起跳" | 确认新增长曲线 |
| 矛盾提炼型 | "增长还是利润？拉美阿里的抉择" | 点出核心trade-off |
| 信仰测试型 | "腾讯：股王照样'深蹲'？考验信仰的时刻到了" | 极端悲观中的价值坚守 |
| 预期管理型 | "腾讯没有惊喜？股王黄金质地藏不住" | 降预期+升质地 |

### 4.2 开篇结构

海豚投研的标准开篇结构（财报点评类）：

1. **一句话总判断**（"增长一般但赚钱加倍"）
2. **关键预期差罗列**（编号1/2/3/4，每条加粗核心结论）
3. **管理层指引对比**（实际 vs 指引 vs 一致预期）
4. **定性判断**（"超预期"归因到具体业务线）

### 4.3 数据呈现方式

**同比增速+绝对值双维度呈现**
不只是看增速，同时关注绝对值的环比变动。例如："广告下滑18%，但绝对值环比并未降低"——这比单纯看增速更能说明问题。

**交叉验证法**
- 用递延收入验证游戏流水的真实性
- 用央行备付金验证支付收入的合理性
- 用行业数据（伽马/SensorTower/QuestMobile）验证公司披露

**趋势外推+基数效应分解**
每次看同比增速，都会拆解基数效应的影响：
- "虽然同比下滑，但去年9月未成年保护政策正式开始实施，没了基数效应后预计下半年会看到好转"
- "高基数下增速放缓是预期内，重点看环比改善趋势"

### 4.4 结尾收束方式

海豚投研的标准结尾结构：

1. **核心观点重申**（"站在目前的位置，大部分风险已经被打入价格"）
2. **催化剂展望**（"年底监管环境缓和，再寻找比较舒服的位置择机介入"）
3. **风险提示**（"大股东抛压对短期股价的负面影响"）
4. **估值锚定**（"目前XX倍PE，属于中性偏低/偏高区间"）

### 4.5 特色表达/金句

- **"全则必缺，极则必反"**——用在极致悲观后的反转判断
- **"躺赚的商业模式掩盖了实际人效比冗余的问题"**——对腾讯组织效率的精准概括
- **"边线战场炮火收回，转投主战场"**——对阿里战略再平衡的形象描述
- **"打铁还需自身硬，主要靠成长，不怕个别股东的非正常减持"**——对回购vs成长的判断
- **"从降速上来看，平地已经临近"**——用物理比喻描述业绩拐点
- **"增长飞轮清晰，护城河够宽"**——简洁有力的投资论据
- **"不是一脚油门踩到底"**——对管理层商业化节奏的描述
- **"一次集体性降本增效，腾讯投资的小兄弟终于不拖后腿了"**——联营公司扭亏的行业性解读
- **"AI革新时期，投入长期成长比维持短期利润更有价值"**——对AI投入周期的判断框架
- **"股王能够轻松转身，得益于其'躺赚'的商业模式"**——商业模式决定转型空间

## 五、行业特色维度

### 5.1 互联网广告的量价拆解

海豚投研对广告的分析建立了三因素模型：

**广告收入 = 流量×加载率×eCPM**

三个驱动因素的分析框架：
1. **流量（量）**：微信MAU增速+视频号DAU/时长 → 库存基础
2. **加载率（量）**：广告填充率提升 → 从5-6%向15%追赶（vs 抖音）
3. **eCPM（价）**：行业性涨价 vs AI提效 vs 商家预算竞争

**视频号广告的增量拆解**：
- 外循环广告（品牌曝光）→ 库存释放驱动
- 电商广告（效果转化）→ 电商GMV增长驱动
- 小游戏激励广告 → IAP/IAA模式拉动

案例：《腾讯：视频号变身摇钱树》中，"剔除视频号的增量影响（外循环+电商广告合计50-60亿，同比增长170%），剩下的广告增速预计也有高个位数至双位数的增长"。

### 5.2 游戏流水的前瞻性指标

**递延收入作为前瞻指标的方法论**

递延收入是海豚投研判断游戏短期趋势的核心指标：
- 大部分递延收入来自"用户还未使用的游戏充值流水"
- 递延收入环比变动 → 预示下季度游戏收入走势
- 但需注意：递延收入也包含音乐/视频/直播的充值流水

**流水vs收入的区别**
- 收入：按确认周期计入（如皮肤按消耗周期分摊）
- 流水：当期实际充值金额，更能反映真实需求
- 流水 = 收入 + 递延收入变动

**长青游戏二次开发战略**
2024年后海豚投研发现了腾讯的新战略——"聚焦长青游戏IP的二次开发"：
- 不再依赖新游爆量，而是对《王者荣耀》《和平精英》等老游戏持续更新内容
- AI助力内容生成，反复刺激用户活跃
- 新游变现效率高于以往（减少外部渠道依赖）

### 5.3 云业务的收入质量

海豚投研对云业务的分析方法论：

1. **增速 vs 利润率的取舍**：阿里云"做大收入仍然是第一要务"（高增速优先），腾讯云"转型高质量增长"（利润率优先）
2. **倒算法**：金科企服总收入 - 估算支付收入 = 云+佣金收入
3. **行业对标**：与Azure增速对比，判断全球竞争力
4. **调整期判断**：腾讯云从"减少低毛利分包"到"恢复正增长"的周期追踪

### 5.4 金融科技/支付的利润结构

**支付业务的拆解方法论**
- 用央行备付金增速推算行业支付增速
- 假设微信支付增速略高于行业（份额提升逻辑）
- 倒算出云业务增速

**金控公司监管的估值影响**
海豚投研对腾讯支付有独立深度分析：
- 金控公司设立"几乎板上钉钉"
- 关键变量：腾讯是否拥有金控公司控制权
- 若失去控制权 → 支付利润不能完全并入上市主体 → 估值大幅影响

**分付/分期的增量逻辑**
信贷产品（分付、分期）是腾讯金科的"第二春"，但测试周期长，需要持续追踪。

### 5.5 回购/分红的估值含义

海豚投研的回购分析框架：
- **回购节奏**：日均回购规模（如"交易日保持每天10亿港元"）
- **大股东抛售**：月均抛售量+持股比例变化
- **净效果**：回购股数 vs 抛售股数 → 总股本净变动
- **资金来源**：经营现金流 + 投资资产处置
- **估值含义**：回购注销 → EPS增厚 → 对股东更友好

核心洞察："有了成长故事的腾讯，看好资金增加，也不需要完全靠自身回购来支撑大股东的抛盘了。打铁还需自身硬，主要靠成长，不怕个别股东的非正常减持。"

### 5.6 腾讯/阿里的特殊分析维度

**腾讯的特殊维度**：
1. 投资组合的隐含价值（联营/合营资产规模 × 投资收益率）
2. 大股东Prosus减持节奏的持续追踪
3. 微信生态商业化的"克制 vs 进取"节奏判断
4. 视频号电商从0到1的生态建设追踪

**阿里的特殊维度**：
1. 淘宝改版（信息流化）对广告收入的拉动
2. 反垄断对二选一的取消 → 平台零售盈利能力的长期影响
3. 组织变革（1+6+N）对各业务线估值的影响
4. 拼多多竞争下的"战争再平衡"模型

## 六、降本增效/战略转型

### 6.1 区分"真改善"和"降本增效"

海豚投研的判断框架：

**"真改善"的信号**：
- 高毛利业务占比提升带来的毛利率改善（收入结构效应）
- 平台规模效应带来的成本摊薄（如服务器带宽成本下降）
- 业务整合带来的效率提升（如减少低效项目）

**"降本增效"的信号**：
- 裁员带来的人均薪酬下降（但研发人员薪酬不降）
- 减少低利润业务（如云业务减少分包）→ 收入也受影响
- 推广支出压缩 → 但可能影响长期增长

**海豚投研的关键判断**：腾讯的降本增效不是简单的裁员，而是一种"滚动式的小幅优化"——
"或许腾讯作为龙头公司，本身有社会责任包袱，一次性优化到位负面影响较大，因此这种滚动式的小步优化也是目前最佳选择。"

### 6.2 评估战略转型的成效

**阿里"1+6+N"分拆的评估框架**
海豚投研对阿里分拆的分析：
- 分拆的隐喻："所有的稀缺都将以过剩终结"——平台红利的终结
- 各业务线的独立造血能力是关键评估维度
- 云业务扭亏是"确定性事件"但增速放缓是隐忧

**腾讯"高质量增长"转型的评估**
- 从"大水漫灌"到"精准投放"的转变
- 评判标准：收入增速下降但利润增速上升是否可持续
- 关键假设：收入三支柱（游戏、广告、支付）不能出大问题

### 6.3 业务分拆/重组的影响分析

**腾讯减持京东/Sea的分析框架**
1. 短期：处置收益确认到其他收益净额（780亿）
2. 中期：减少联营公司的分占亏损
3. 长期：失去联营公司盈利后的分占利润
4. 对股东：短期直接处置带来的利润更实际有效

核心洞察："对于持股年限不会非常长的中小股东来说，短期直接处置带来的利润更实际有效一些。"

## 七、新发现（之前skill未覆盖的）

### 7.1 平台型公司的规模效应量化方法

海豚投研发现了一种量化平台规模效应的方法：
- 当收入增速10%+时，核心经营利润增速可达30-50%
- 杠杆来源：①高毛利业务占比提升 ②固定成本摊薄 ③费用率优化
- 这不是简单的"裁员效应"，而是平台型商业模式的内在优势

### 7.2 AI对互联网平台的三层影响模型

海豚投研从腾讯的实践中提炼出AI影响的三层模型：
1. **应用层**：AI提高广告ROI → 逆势高增长
2. **内容层**：AI生成内容 → 长青游戏的二次开发
3. **效率层**：AI替代基础开发 → 组织效率长期优化空间

关键判断："虽然短期有较高的前置投入，但长期来看能够持续优化基础开发资源成本。"

### 7.3 电商大战的"隔岸受益"逻辑

当电商竞争白热化时，非直接竞争的流量渠道反而受益——这是一个反直觉但可复用的分析逻辑。

具体传导：电商内卷 → 商家需要更多流量 → 腾讯等"中立"渠道成为必选 → 广告收入逆势增长

### 7.4 联营公司盈利的行业性信号

海豚投研发现：腾讯联营/合营公司从亏损转为盈利，不是腾讯独有的现象，而是整个互联网行业"集体性降本增效"的信号——这是一个从个体数据推断行业趋势的方法论。

### 7.5 付费用户流失的"结构性改善"解读

当付费用户流失但ARPPU提升时，海豚投研不简单视为负面，而是解读为：
- 流失的是"非忠诚""非氪金"用户
- 留下的是核心用户 → 付费率提升+单用户付费走高
- 这是消费疲软下的"提纯"效应，反衬商业模式的韧性

### 7.6 递延收入季节性偏离法

不只看递延收入的绝对值，更看"环比变动幅度 vs 历史惯常季节性波动"的偏离：
- 偏离幅度小于历史惯常 → 流水稳定性提升
- 偏离幅度大于历史惯常 → 可能有异常因素

## 八、代表性金句和表达

### 分析方法论类
- "通过回溯各项收支来看，主要由毛利率比市场预期高1个点造成的预期差"——归因到1个百分点的精度
- "按照Non-IFRS调整口径，在原来净利润的基础上剔除掉投资、摊销以及股权激励的影响"——三层利润穿透法
- "海豚君粗略估算，剔除视频号的增量影响"——增量归因法
- "从第三方支付机构上交给央行的备付金规模增速来看"——用监管数据交叉验证

### 投资判断类
- "目前的价格理论上已经将腾讯经济环境、行业周期反转之后的修复和成长性预期都给打没了"——极致悲观的定价判断
- "从长期来看，腾讯的价值还是会回归到基本面上"——价值回归信仰
- "当下更重要的在于寻找腾讯的业绩拐点"——拐点比估值更重要
- "在个位数收入增长下，保持利润双位数增速的中长期趋势"——新常态的盈利增长模型

### 行业洞察类
- "当龙头渠道都开始用上了AI来提高广告转化后，各家就又回到了竞争起点——拼流量硬实力的时候"——AI红利是短暂的
- "作为用户粘性最高、规模最大的平台，微信也被商家视为真正意义上的私域流量最后聚集地"——私域价值的底层逻辑
- "优秀的商业模式掩盖了腾讯也存在的组织臃肿、人效比不高的问题"——商业模式对管理问题的遮蔽效应
- "整个行业长视频会员也就是2~3亿，最多也就是对应10亿网民，3口一家，也就是3亿多的潜在账户数"——用简单算术验证天花板

### AI时代类
- "AI革新时期，投入长期成长比维持短期利润更有价值"——投资周期的判断框架
- "AI同样能够助力互联网平台运营效率的提升——虽然短期有较高的前置投入，但长期来看能够持续优化基础开发资源成本"——AI的成本曲线判断
- "海豚君依然看好腾讯能够在AI时代，发挥出更多'超预期'的增长潜能"——成长想象力驱动估值

## 附录：海豚投研分析SOP

基于以上提炼，海豚投研的财报分析SOP可概括为：

1. **预期基准建立**：一致预期 + 管理层指引 + 投行预期
2. **收入逐项拆解**：四柱/三层框架，每项对比预期，识别预期差
3. **利润三层穿透**：核心经营利润 → Non-IFRS净利润 → GAAP净利润
4. **预期差含金量判断**：区分核心经营改善 vs 一次性/外部因素
5. **产业链交叉验证**：用行业数据/监管数据/竞品数据验证公司披露
6. **竞争格局定位**：时长份额/GMV增速/行业对比
7. **战略转型评估**：战争再平衡/高质量增长/降本增效的区分
8. **估值锚定**：PE + 投资资产折价 + 净现金
9. **催化剂展望**：短期边际改善 + 中长期增长飞轮
10. **风险提示**：大股东抛压/监管/竞争/宏观
