# 美股科技巨头分析框架

> 覆盖：苹果/微软/谷歌/亚马逊/Meta/Netflix/Spotify
>
> 数据来源：基于海豚研究148篇美股互联网研报深度提炼

## 一、美股科技巨头的核心分析逻辑

```
美股科技巨头 ≠ 中概互联网
核心差异：
├── 第二曲线面向全球企业市场（云+AI），天花板远超中概
├── 回购+分红是估值支撑工具，而非仅信心信号
├── DCF估值是标配，PE只是辅助
├── AI Capex是核心变量——决定未来3-5年利润率走势
└── "两条腿走路"的公司有明确安全边际
```

### 1.1 五大商业模式的区分

| 模式 | 代表公司 | 核心收入 | 关键变量 |
|------|---------|---------|---------|
| **云+软件订阅** | 微软/谷歌 | Azure/云+M365/订阅 | RPO增速、ARPU×坐席数 |
| **广告+AI赋能** | 谷歌/Meta | 搜索广告/社交广告 | 展示量×CPM、Ad Load |
| **电商+云+广告** | 亚马逊 | 零售+AWS+广告 | GMV、AWS增速、广告take rate |
| **硬件+服务生态** | 苹果 | iPhone+服务 | 硬件ASP×出货量、服务占比 |
| **纯订阅** | Netflix/Spotify | 会员订阅 | 用户数×ARPU、内容成本率 |

## 二、核心指标体系

### 2.1 云业务指标（微软/谷歌/亚马逊）

| 指标 | 含义 | 关注方式 |
|------|------|---------|
| **云收入增速** | 增长动力 | >30%=高景气；<20%=放缓信号 |
| **待履约合同余额（RPO）** | 未来收入可见性 | **核心先行指标！**环比净增>10%=强 |
| **云业务利润率** | 盈利拐点 | 从亏损到盈利=估值重估催化剂 |
| **AI vs 非AI增速贡献** | 内部替代效应 | AI贡献pct vs 传统业务减速pct |
| **Capex/收入比** | 投入强度 | >30%=激进；>50%=危险信号 |
| **新签合同增速** | 签单势头 | >30%=未来2-3季度收入有保障 |

**云业务增长-利润"三段式"判断**：
```
第一阶段：高增长+亏损（投资期）
├── 关注：收入增速、RPO增速、签单势头
├── 估值锚：EV/Revenue（PS）
└── 案例：谷歌云2023年之前

第二阶段：高增长+微利（拐点期）
├── 关注：利润率改善斜率
├── 估值弹性最大！从PS切换到PE
└── 案例：谷歌云2023年扭亏，利润率攀升至30%

第三阶段：增速放缓+高利润率（成熟期）
├── 关注：护城河、现金流、股东回报
├── 估值锚：PE+FCF
└── 案例：AWS当前状态
```

### 2.2 广告业务指标（谷歌/Meta）

| 指标 | 含义 | 关注方式 |
|------|------|---------|
| **展示量增速** | 广告库存 | Ad Load提升空间×用户时长 |
| **CPC/CPM增速** | 广告定价 | 经济周期的"温度计" |
| **广告加载率（Ad Load）** | 变现杠杆 | 加载率↑但用户体验↓的平衡 |
| **ATT/隐私政策影响** | 追踪能力下降 | 搜索广告受益，社交广告受损 |
| **AI赋能广告效率** | ROAS提升 | AI→精准投放→CPM↑→收入↑ |

**广告量价关系四象限**：
```
         价↑          价↓
量↑  ┌─ 繁荣期 ──┬─ 衰退早期 ─┐
     │ 广告主抢量 │ 广告主砍预算 │
     │ CPM上升    │ 平台降价保量 │
量↓  ├─ 过热期 ──┼─ 衰退期 ───┤
     │ 供给有限   │ 量价齐跌     │
     │ 需求旺盛   │ 最差情况     │
     └──────────┴───────────┘
```

### 2.3 订阅业务指标（Netflix/Spotify/苹果服务）

| 指标 | 含义 | 关注方式 |
|------|------|---------|
| **订阅用户数** | 规模 | 增速+天花板判断 |
| **ARPU** | 单用户价值 | 提价能力vs用户流失风险 |
| **付费转化率** | 免费→付费 | Spotify vs 腾讯音乐差异巨大 |
| **内容成本率** | 成本控制 | Netflix现金内容投入vs自制占比 |
| **流失率（Churn）** | 用户粘性 | <5%/月=优秀 |

### 2.4 硬件+服务生态指标（苹果）

| 指标 | 含义 | 关注方式 |
|------|------|---------|
| **iPhone ASP** | 硬件定价 | Pro系列占比提升→ASP↑ |
| **服务收入占比** | 利润结构迁移 | 每+1pct→整体毛利率+0.3-0.4pct |
| **服务毛利率** | 70%+ | "软件吃硬件"利润迁移 |
| **活跃设备安装基数** | 服务收入底盘 | 决定服务收入天花板 |
| **回购规模** | EPS支撑 | 回购缩水=Capex挤压的信号 |

## 三、AI Capex ROI分析框架

### 3.1 Capex→折旧→利润率传导链

```
【AI Capex的财务影响四步分析】

Step 1: Capex消化能力测算
├── 将超额Capex按折旧年限分摊，与额外收入增量做对比
├── 例：谷歌2026年比预期多投500亿
│   → 按5年摊销，年多占50-100亿利润
│   → 但若云增速从35%→40%，额外收入可覆盖
└── 核心问题：增量收入能否覆盖增量折旧？

Step 2: 现金流冲击三层分析
├── 第一层：经营现金流能否覆盖Capex？
│   Meta案例：一年经营现金流几乎"一键清零"
├── 第二层：融资手段是否可持续？
│   Meta发债300亿+表外融资273亿（Blue Owl，隐含10.7%利率）
└── 第三层：股东回报是否被迫压缩？
    谷歌Q4回购缩水60亿，Meta股东回报空间"非常低"

Step 3: "AI宠儿"vs"AI败家子"叙事反转
├── Capex增速显著超过收入增速时 → 叙事反转
├── Capex/收入比>50% → 危险信号
├── 按5.5年服务器折旧周期 → 年额外7pct利润率压力
└── 案例：Meta从"最广泛AI场景"到"利润率崩盘"只花一个季度

Step 4: 判断AI Capex可持续性
├── 云业务RPO是先行指标（微软$2980亿、谷歌2400亿、AWS 805亿）
├── "余粮"充足→可持续；"余粮"不足→可能被迫缩减
├── Deepseek效应：可能降低AI训练对硬件的需求→军备竞赛降温催化剂
└── 供给约束：电力和台积电产能"捏住了AI的命门"
```

### 3.2 AI变现进度三层级

```
第一层（已兑现）：AI基础设施
├── Azure AI贡献13pct增速
├── 谷歌云+48%
└── 验证信号：RPO增速、云收入加速

第二层（早期）：AI应用
├── Copilot推动M365客单价+8.4%
├── AI赋能广告→CPM提升
└── 验证信号：ARPU提升、渗透率

第三层（未来）：AI原生业务
├── Meta AI、Google Gemini、Agent
├── 搜索是2C端最有效的AI应用方向
└── 验证信号：新收入线出现

⚠️ 注意：AI vs 非AI的内部替代效应
Azure AI贡献13pct增长，但非AI业务增长贡献大幅下降3pct
→ AI对云巨头当期收入的净拉动可能低于预期
```

### 3.3 AI对毛利率的"不对称影响"

| 业务类型 | 短期影响 | 长期影响 | 关键变量 |
|---------|---------|---------|---------|
| 云业务 | 毛利率↓（投入期折旧） | 毛利率↑（规模效应） | 利润率拐点时点 |
| 广告业务 | 中性（AI提升转化率但也增加成本） | 略↑（AI提效降本） | AI广告ROAS提升幅度 |
| 硬件业务 | 毛利率可能↑（AI PC/iPhone提价） | 不确定 | AI功能对ASP的拉动 |

## 四、第二曲线判断框架

### 4.1 美股科技巨头的"第二曲线"图谱

```
微软：Office ──→ Azure ──→ AI（Copilot）
     ✅三条曲线成功切换，"老当益壮"

谷歌：搜索广告 ──→ YouTube ──→ 云业务 ──→ AI
     ✅多条曲线并行，"两条腿走路"

亚马逊：电商 ──→ AWS ──→ 广告
     ✅"意外"的第二第三曲线

Meta：社交广告 ──→ Reels ──→ AI赋能广告
     ⚠️在原有业务上叠加AI，没有真正的"新赛道"

苹果：iPhone ──→ 服务 ──→ AI（潜力）
     ⚠️"零成长摇钱树"的困境，AI曲线尚未成型
```

### 4.2 第二曲线的评估标准

| 评估维度 | 核心问题 | 判断方法 |
|---------|---------|---------|
| **TAM天花板** | 第二曲线面向的市场有多大？ | 全球企业市场>>单一国家消费市场 |
| **增速与确定性** | 增速快但不确定 vs 慢但确定？ | 云业务确定性>消费互联网 |
| **全球化 vs 本土化** | 能否复制到全球？ | 美股"AI+云"面向全球，天花板远高于中概 |
| **与第一曲线的协同** | 飞轮效应还是资源分散？ | 微软Office→Azure协同 vs 苹果硬件绑定服务 |

### 4.3 中概vs美股的核心差异

```
美股科技巨头：
├── 第二曲线：云+AI，面向全球企业市场
├── 天花板：全球企业IT支出（万亿美元级）
├── 估值支撑：DCF+PE双轨，回购+分红支撑
└── 核心优势："两条腿走路"的公司有明确安全边际

中概互联网：
├── 第二曲线：海外/新业务，天花板不确定
├── 核心困境：国内广告+游戏存量竞争
├── 估值折价：VIE架构+监管风险+回购力度弱
└── 关键洞察："主营遭遇瓶颈、没有第二曲线的公司在收水中下跌尤其惨烈"
```

## 五、回购/分红的估值含义

### 5.1 美股vs中概的回购差异

| 维度 | 美股巨头 | 中概互联网 |
|------|---------|-----------|
| **规模** | 年化数百亿美元 | 年化数十亿港元 |
| **性质** | 估值支撑工具（影响EPS） | 信心信号（影响情绪） |
| **约束** | Capex挤压时回购缩水 | 政策和治理限制 |
| **Cash Neutral模式** | Meta"赚多少花多少" | 不适用 |

### 5.2 回购缩水是基本面信号

```
Meta现金流拆分（Cash Neutral模式）：
现金流入：主营获利
现金流出：业务投入 + 股东回报 + 对外投资
当Capex飙升时 → 主要压缩股东回报和对外投资
→ 回购缩水 = Capex挤压的信号
```

## 六、估值方法

### 6.1 不同公司的估值锚

| 公司 | 主要估值方法 | 关键变量 | 估值争议 |
|------|------------|---------|---------|
| 微软 | DCF + PE | WACC、永续增长率 | PE处于三年均值即合理 |
| 谷歌 | DCF + PE | 云业务利润率拐点 | 搜索广告天花板 |
| 亚马逊 | P/CFO | AWS增速、经营现金流 | P/CFO处于均值-1σ以下=低估 |
| Meta | PE（波动极大） | AI Capex/收入比 | 7x（2022底）到25x+（AI宠儿期） |
| 苹果 | PE | 服务占比、回购力度 | "30倍PE"之争=增长vs利润质量 |
| Netflix | PE/FCF | 内容投入节奏、用户增长 | 从PS→PE的估值切换 |
| Spotify | EV/用户 | 付费转化率、ARPU | 与腾讯音乐对比估值 |

### 6.2 DCF估值的关键假设

```
WACC选择：
├── 微软：7.79%（低风险，高确定性）
├── 亚马逊：9.67%（中等风险）
└── Meta：10%+（高Capex风险）

永续增长率：
├── 2.5%（基准假设）
├── 敏感性分析：1.5%-3.5%区间
└── 注意："不同折现率下的估值区间"比单一目标价更有价值

DCF的三大膨胀→三大压缩：
1. 行业增速提升→提估值 / 即期增速下降→压缩
2. 高增速年限假设提升→再提 / 长期年限证伪→压缩
3. 折现率下降→最后提 / 折现率抬升→压缩
```

## 九、分析要点清单

1. **AI Capex消化能力**：增量收入能否覆盖增量折旧？
2. **RPO/待履约合同**：未来2-3季度收入是否有保障？
3. **第二曲线位置**：公司是否有"两条腿走路"的安全边际？
4. **回购力度变化**：回购缩水是否因Capex挤压？
5. **AI vs 非AI替代**：AI增量是否被传统业务减速抵消？
6. **广告量价关系**：处于繁荣/过热/衰退四象限的哪个位置？
7. **云业务利润率拐点**：从亏损到盈利是估值重估最强催化剂
8. **估值方法适配**：DCF还是PE？P/CFO是否更合适？
9. **中概vs美股对比**：第二曲线天花板、回购力度、估值折价
10. **叙事反转信号**：Capex/收入比>50%="AI宠儿"→"AI败家子"
