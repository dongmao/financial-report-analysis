> 基于11篇海豚研究研报提炼，涵盖快手（4篇）、百度（4篇）、小米（3篇）。网易研报未在文件列表中出现。

## A. 内容/短视频行业分析（快手）

### A1. DAU/MAU分析框架

**方法论：电商属性强化后，用户活跃度节奏从"娱乐季节性"转向"电商季节性"**

- **案例**：快手《双飞轮带动，利润藏不住》（24Q1）——"随着快手电商属性占上风，用户活跃度的变化可能转变为与电商旺淡季变动更一致（二、四季度用户增长更高），而非往年娱乐属性更强时随寒暑假变动。"
- **关键指标组合**：MAU绝对值 + DAU/MAU（粘性） + 日均时长 + 单日总用户时长（=DAU×日均时长，核心流量指标）
- **预期差发现**：第三方数据（QM）与公司披露数据常有差异，Q4财报中QM显示总用户时长同比负增长，但公司披露同比增5.8%——"如果市场主要以第三方平台的数据作为参考的话，那么会有一个小预期差"

**方法论：用户增长质量评估——"获客+维系成本"指标**

- **案例**：快手《AI能带飞老铁经济吗？》（25Q4）——海豚君自建"用户获得+维系成本"指标（推广费用/MAU增量），发现Q4该指标同比走高，"说明就算流量是稳步扩张的，但当期月活的增加背后，有着公司更多的推广费用+内容投入"
- **判断逻辑**：MAU扩张 + 获客成本走高 = 运营效率边际走低，需要谨慎看待流量"增长"

### A2. 内容成本与直播生态分析

**方法论：直播治理"对冲法"——一边治理，一边引入优质供给**

- **案例**：快手《双飞轮带动》（24Q1）——"相比同样治理生态的腾讯音乐、云音乐，快手的直播收入并未有恐慌式滑坡，可能是一边治理，一边加速引入优质公会（Q1同比增长50%），抵消了对短期业绩拖累"
- **推演**：延续这个操作趋势，预计全年直播收入10%以内下滑，而非市场担忧的断崖

**方法论：倒算分成比例判断直播生态**

- **案例**：快手《AI能带飞》（25Q4）——"海豚君倒算出的直播收入分成成本比例，四季度付给主播的分成比例预计有所提高，可能是优质公会要求更高的分成比例或者固定佣金"
- **洞察**：分成比例上升 = 优质供给的代价，短期内拉低毛利率但中长期有利生态健康

### A3. 变现效率分析：广告+电商+直播三维拆解

**方法论：广告"内外循环"拆分法**

- **案例**：快手系列研报——海豚君始终将广告拆分为"电商广告（内循环）"和"外循环+联盟广告"两部分：
  - 电商广告增速跟随GMV变化
  - 外循环广告才是观察宏观+竞争的真正窗口
- **行业归因**：快手《双飞轮》——"短剧（付费投流）、游戏（元梦vs蛋仔买量）、教育（素质教育需求火热）"是拉动外循环广告的行业级增量
- **竞争传导**：快手《AI能带飞》——"短剧算是一种完全意义上的增量需求，试想如果没有短剧，除短剧之外的外循环广告内生增速又能有多少增速呢？"

**方法论：电商综合变现率（佣金+广告）的追踪**

- **案例**：快手《双飞轮》（24Q1）——"如果按照电商广告占比50%左右来估算，预计佣金+广告的综合变现率达到4.3%，同比增加0.7pct，已经逼近此前快手对自己的稳态目标4.5%"
- **变现率提升归因三动作**：全站推广 + 削番/扶持中小主播 + 协助品牌自播——"三个动作，本质上就是缩短自己与商家之间的利益链条，从而瓜分到更多的产业链利润"
- **后续反转**：快手《AI能带飞》（25Q4）——佣金率1.06%同比略下滑，"除了积极引入新商家而必需的返佣让利外，也与行业竞争激烈有关"

**方法论：平台与主播的"流量分配vs利益分配"矛盾**

- **案例**：快手《双飞轮》——"流量分配和盈利分配的矛盾随着平台增长需要，必然会发生。虽然短期负面影响不可避免（快手私域属性较重），但伤筋动骨倒不至于（7亿规模的社交平台，流量话语权大部分还是握在平台手中）"
- **泛货架转型是关键**：从"人找货"场景做更多价值挖掘，Q1泛货架电商GMV占比25%（环比+5pct）

### A4. AI对内容行业的影响分析

**方法论：AI对平台的"开源"与"节流"二分法**

- **案例**：快手《AI能带飞》（25Q4）——海豚君将AI对快手的影响分为：
  - **开源（做增量收入）**：可灵收费 + AI提升推荐精准度→增加用户粘性和广告ROI
  - **节流（节省开支）**：员工替代、资源复用、经营摩擦成本减少
- **核心判断**："开源"对估值提升更明显（带来预期差），但"指望AI为快手带来新增长飞轮，可能还是偏乐观了"
- **理由**：①DS后AI能力同一起跑线，技术不能增加相对优势；②短视频推荐和广告分发本身已经足够高，AI边际提升有限

**方法论：AI消除"资金偏见"，实现估值纠偏**

- **案例**：快手《AI能带飞》——"AI行情起来后，拥有可灵的快手，已经逐步走入更多的投资人视野，再加上相对低估值，短中期内资金关注度的提升，会相对拉高快手的整体估值区间"
- **金句**："估值的空间，全看AI情绪"

## B. 搜索/AI行业分析（百度）

### B1. 搜索广告的量价拆解

**方法论：搜索广告的"份额侵蚀"分析框架**

- **案例**：百度《搜索王国》（24Q1）——"搜索广告份额一直在被短视频、电商等其他广告类型侵蚀，目前仅低个位数占比的AI广告还远远不够填坑。而对岸的Meta和Google，在传统业务竞争缓解的同时，AI还贡献了10%左右的收入份额"
- **关键对比**：百度 vs 海外同行——Google/Meta的AI已贡献10%收入，百度仅1-2%

**方法论："巨头拆墙"红利的消退分析**

- **案例**：百度《翻盘只能靠AI》（23Q4）——"巨头拆墙、电商平台恶战的红利期走完，接下来又是比拼各自用户规模、粘性、转化率这些硬实力上来了，但这些百度除了规模，其他都不占优势"
- **推演**：红利消退后，百度的广告增速将回归"随宏观波动"的状态

**方法论：同行横比法——在逆风期放大竞争差距**

- **案例**：百度《搜索王国》——海豚君拉出非电商平台的广告增速趋势对比（腾讯、快手非电商、微博、B站、百度），"在增长逆风期，平台之间的竞争差距也会显得更大"

### B2. AI变现的进度评估

**方法论：AI收入"填坑"vs"增量"的二分判断**

- **案例**：百度《搜索王国》——"AI还只是将将补足传统广告被同行挤压的缺口，额外的拉动还没有明显看到"
- **判断标准**：AI收入占收入比例 > 传统广告被侵蚀的份额，才算真正"增量"

**方法论：AI搜索的"饮鸩止血"悖论**

- **案例**：百度《Deepseek成灵魂摆渡》（25Q1）——"新增的流量显然粘性主要在AI搜索页面，这使得传统搜索广告无法直接受益流量的回暖"
- **核心矛盾**：AI搜索带来流量，但无法直接变现；AI搜索商业化又可能伤害用户体验
- **进度评估**：百度AI搜索商业化"在极其早期阶段，要一步一步慢慢走"——意味着二三季度广告可能加速下滑

**方法论：AI云业务"铲子商"逻辑**

- **案例**：百度《Deepseek成灵魂摆渡》——"百度算是误打误撞第一波吃满了DeepSeek红利的平台"，智慧云增速从28%飙至42%
- **关键动作**：快速接入 + 全网最低价 = 短期增长红利
- **但中长期判断**：百度内在竞争力所能体现的中长期增长，光看一季度业绩还是很难说服我们完全改观

**方法论：新架构披露下的AI含量追踪**

- **案例**：百度《广告寒冬漫漫》（26Q4）——百度正式采用新架构披露，分为AI业务和传统业务。"AI含量继续提升至43%"，但传统广告还在下滑26%
- **关键洞察**：AI收入占比提升不等于公司整体在变好——结构变化（低毛利业务占比提升）会对整体盈利产生长期影响

### B3. 云业务的收入质量分析

**方法论：云业务增速的"三因素拆解"**

- **案例**：百度《翻盘只能靠AI》（23Q4）——云增速回暖归因为：①低基数（上年同期ACE滑坡）+ ②AI对GPU租用/API调用的拉动 + ③企业客户MaaS平台工具改进
- **但AI占比仍低**：4Q23 AI相关云收入仅约2.7亿（占云收入4.8%）

**方法论：资本开支作为AI投入的"先行指标"**

- **案例**：百度系列研报——海豚君持续追踪百度的资本开支趋势，作为判断AI投入节奏的领先指标：
  - 23Q4："从资本开支上，能更清晰看出公司持续增加投入的趋势"
  - 25Q1："资本开支重启扩张，或因芯片限购下提前抢买的考虑"
  - 26Q4："Capex下降到不足20亿，应该不是常态"

## D. 硬件+生态分析（小米）

### D1. 硬件ASP×销量的拆解

**方法论：手机量价分拆——国内vs海外双线分析**

- **案例**：小米《一手汽车一手国补》（25Q1）——海豚君将手机出货量拆分为国内/海外：
  - 国内：国补推动销量同比+40%，市占率18.6%历史新高
  - 海外：销量同比下滑8.9%，尤其印度-38%
  - ASP：国内占比提升→整体ASP稳定在1200元上方
- **关键洞察**："国内手机销量占比已提升至公司总体的3成以上"，结构性变化是ASP和毛利率的隐性驱动力

**方法论：手机毛利率的成本拆解——零部件涨价vs结构改善**

- **案例**：小米《一手汽车一手国补》——"受核心零部件成本增加的影响，手机毛利率同比回落至12.4%。但即便如此，本季度传统业务毛利率仍好于市场预期，主要还是IoT毛利率提升的带动"
- **判断**：短期毛利率受成本周期影响，但长期靠高端化（国内占比提升）对冲

### D2. 互联网服务的边际利润

**方法论：小米互联网服务的"分发税"逻辑**

- **案例**：小米《一手汽车一手国补》——"小米广告所占据的核心广告场景——应用分发和APP预装，几乎是各大APP厂商必交的分发税，尤其是APP预装，其实和手机出货量强相关，广告几乎是躺赚"
- **但**：增值业务（游戏分发、有品、金融）基本不增长，"金融在宏观逆风下蛰伏、游戏分发渠道话语权下降"
- **判断**：互联网服务长期依附于硬件出货量，当汽车业务毛利率反超互联网服务时，整体商业逻辑已变

### D3. "手机×IoT×互联网服务"的飞轮分析

**方法论：小米飞轮的"三阶段"演进**

- **案例**：小米《一夜成神》（25年3月）——海豚君梳理小米上市以来的战略演进：
  1. **IPO期**：说自己是互联网公司，硬件是用来拿流量
  2. **华为横扫期**：打出IoT再造小米、国际再造小米、高端重塑小米三张牌
  3. **汽车成功期**：汽车成为真正"再造小米"的引擎
- **金句**："无论哪一张牌打出来，基本都是高高举起、风光一时，似乎又石沉大海"——直到汽车成功

**方法论："幸福三重奏"共振分析法**

- **案例**：小米《一夜成神》——海豚君识别三重利好共振：
  1. **汽车**：SU7交付越多，订单越多（"交付越多，订单越多"的奇特现象）
  2. **国补**：从家电到手机，小米全系产品落入国补标准
  3. **端侧AI**：DeepSeek降低AI硬件门槛→加速换机逻辑
- **判断**：三重利好同期共振，但各自持续性不同——汽车看品牌号召力能否持续，国补看政策延续性，AI看换机周期兑现

### D4. 汽车业务的分析框架

**方法论：汽车估值从"短期销量"到"中长期格局"的切换**

- **案例**：小米《一夜成神》——"市场对小米汽车业务的估值定价从短期视角切换到了中长期视角"
- **逻辑**：SU7交付等待10个月+ → 有车就能卖 → 市场开始线性外推 → 估值从当期销量切换到终局市占率
- **估值方法**：假设2029年月销接近10万台（与理想同期水平），参考纯电新势力最高PS倍数（小鹏），给予稳态2X PS + 10% WACC风险折价

**方法论：汽车毛利率的产能利用率弹性**

- **案例**：小米《一手汽车一手国补》——"一期工厂设计产能15万/年，月产能利用率接近200%"，汽车毛利率从20.4%提升至23.2%
- **归因**：①产能利用率提升的规模效应 + ②SU7 Ultra高定价车型带动ASP + ③产量调配结构优化
- **前瞻**：当订单排产周期从10个月下降至3-5周时，PS估值将回归同行水平

**方法论：汽车"供给端驱动"vs"需求端驱动"的逻辑切换**

- **案例**：小米系列——当前小米汽车仍是"供给端驱动"（有产能就能卖），此时享受较高PS估值
- **关键转折信号**：订单等待时间缩短、需要营销获客时，逻辑从"产能故事"转为"竞争故事"

### D5. 困境反转的"三支箭"框架

**方法论：困境反转的递进式判断**

- **案例**：小米《困境反转的三支箭》（22年12月）——海豚君在小米最悲观时提出：
  1. **第一支箭——库存消化**：自建"真实成品库存"指标（存货-原材料+减值准备），发现Q3下降70亿，远超市场看到的存货减少
  2. **第二支箭——手机出货回暖**：海外优先于国内恢复，EMEA市占率持续提升
  3. **第三支箭——造车落地**：汽车问世后消化造车费用
- **判断节奏**："一支箭、一支箭地落地，陆续迎来边际向好"
- **估值双情景**：A）加回汽车研发费用的正常经营估值；B）假设造车失败的最悲观估值——两个情景之间的差额，就是市场对汽车业务的定价空间

## E. 共性方法论

### E1. 预期差分析案例

**案例1：快手利润超预期的"三分法"归因**
- 《双飞轮》（24Q1）——核心经营利润beat一致预期65%，海豚君拆分预期差的13亿：1/3来自收入超预期 + 1/3来自成本优化 + 1/3来自经营费用超预期收缩
- **方法论**：利润超预期不能简单归因为"公司做得好"，必须拆分成收入/成本/费用三端，分别判断持续性

**案例2：百度"引导后预期"的陷阱**
- 百度《翻盘只能靠AI》（23Q4）——"市场预期受公司引导，已经有过下调，预期偏保守，因此这份财报超预期的质量相对一般"
- **方法论**：区分"超公司引导后预期"和"超原始市场预期"，后者才代表真正的超预期

**案例3：小米库存消化的"隐性强于表面"**
- 小米《困境反转的三支箭》——存货环比减少58亿看似一般，但剔除原材料和减值后，真实成品库存下降70亿，"库存消化存在超市场预期的情况"
- **方法论**：财务报表的表面数字可能掩盖真实趋势，需要自建调整指标

### E2. 毛利微观拆解案例

**案例1：快手毛利——业务结构+组织效率双驱动**
- 《双飞轮》（24Q1）——"高毛利的电商收入增长超预期 + 带宽服务器优化周期 + 管理费用同比对半砍"
- 进一步拆分本土/海外："盈利改善主要贡献来自业务部门而非总部中台"——总部优化效果放缓，后续靠业务层面变现效率

**案例2：百度毛利——结构变化的隐性拖累**
- 百度《广告寒冬漫漫》（26Q4）——"低毛利率的其他收入占比相比上季度提升了2pct，但毛利率环比持平，说明创新业务（尤其是智驾业务）的UE模型在继续改善"
- **方法论**：当低毛利业务占比提升时，整体毛利率持平本身就意味着该业务的UE在改善

**案例3：小米毛利——国补的结构性影响**
- 小米《一手汽车一手国补》——IoT毛利率25.2%同比+5.3pct，但"主要是大家电毛利率比较高，在国补推动下同比增长113%的结构性拉高"
- **警惕**：需区分"真实盈利能力提升"和"高毛利品类结构性增长带来的毛利率提升"

### E3. 产业链传导分析案例

**案例1：百度广告的"下游行业景气度"传导**
- 百度《搜索王国》——医疗、文旅等线下场景回流→百度广告短期受益→但红利消减后又回到流量竞争的本质
- **传导链**：宏观经济 → 下游行业景气 → 广告主投放意愿 → 平台广告收入

**案例2：小米"国补→IoT→毛利率"的传导**
- 国补政策 → 小米IoT产品（家电、平板、可穿戴）符合补贴标准 → 销量爆发 → 高毛利大家电占比提升 → IoT毛利率超预期
- **后续关注**：国补退坡后的基数效应

**案例3：百度DeepSeek→云→流量→广告的链式反应**
- DeepSeek大火 → 百度快速接入+全网最低价 → 智慧云增速飙至42% + 手百MAU净增4500万 → 但新增流量粘性在AI搜索 → 传统广告无法受益 → AI搜索商业化缓慢
- **方法论**：一条产业链传导中，每一步的受益方和受益程度可能不同，需要逐环节验证

### E4. 叙事特色与金句

**叙事结构特色：**
1. **观点先行**：每篇研报开头"具体来看"列出5-7个要点，每个要点有明确判断（超预期/符合/低于预期），先给结论再展开
2. **对比锚定**：频繁使用同行横比（腾讯vs快手vs百度广告增速、海外Meta/Google vs百度AI进度），让读者有参照系
3. **自建指标**：海豚君常用自建指标来发现预期差——"核心经营利润"（剔除政府补贴/理财收入）、"真实成品库存"（存货-原材料+减值）、"用户获客+维系成本"、"综合变现率（佣金+广告）"
4. **递进式推演**：从当期数据 → 行业趋势 → 竞争格局 → 估值影响，层层递进

### E5. 估值方法论

**方法论1：分部估值（SOTP）的适用场景**
- 小米《一手汽车一手国补》——传统业务给20-25x PE，汽车业务给PS估值（当前供给驱动逻辑下享受较高PS）
- 百度——剔除净现金后的实际PE仅4x，但市场不给估值因为"老业务没吸引力+回购不够"

**方法论2：困境反转的双情景估值**
- 小米《困境反转的三支箭》——A情景（加回汽车研发）和B情景（造车失败），两情景差额即为市场对汽车的定价

**方法论3：回购收益率的底部支撑判断**
- 百度系列——海豚君持续追踪回购规模和股东回报率（2%→6.5%→7%），作为估值底部的支撑逻辑
- 快手系列——"回购略表心意式回馈股东"，36个月160亿港元回购计划，"平均到每年的股息率为2%，也不算特别高"

**方法论4：净现金调整后的真实估值**
- 百度——"290亿美金市值，剔掉近190亿净现金，实际也就100亿美金估值，对应25年180亿人民币净利润，PE也就四倍"
- **海豚君判断**：低PE不等于低估，可能是价值陷阱——"在萝卜快跑和智能云跑出个样子之前，这个价格还是价值陷阱"
