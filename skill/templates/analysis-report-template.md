# 财报分析报告模板

> **注意**：这是一个输出格式参考框架，而非强制填空的模板。
> 
> 实际分析时请根据公司特点和用户需求灵活调整——**内容质量 > 形式完整**。

---

## 报告结构总览

```
财报分析报告
│
├── A. 报告头（元信息）
├── B. 执行摘要（30秒版）⭐ 最重要！
├── C. 核心数据仪表盘
├── D. 深度分析（六维模型展开）
├── E. 风险评估
├── F. 前瞻与展望
├── G. 估值判断
├── H. 综合结论
└── I. 附录 + 交互引导
```

---

## A. 报告头

```markdown
---
**公司名称**：[XXX] （股票代码：XXX）
**报告期**：202X年QX（截至 YYYY-MM-DD 发布）
**分析师**：财报分析专家系统
**数据来源**：[neodata API / 公司财报 / 用户提供的材料]
**报告时间**：YYYY-MM-DD HH:MM
**数据截止日期**：[标注所用数据的最新时点]
---
```

## D. 深度分析（六维模型）

### D1. 增长质量
- 当前增速 vs 趋势 vs 行业 vs 预期
- 增长驱动因素拆解（价×量 / 业务线贡献 / 用户×ARPU等）
- 增长质量评级（🟢高质量 / 🟡中等 / 🔴低质量）

### D2. 盈利能力
- 毛利率变动归因
- 费用率拆解及杠杆效应
- 利润拐点判断

### D3. 现金流与风险
- OCF/净利润比率
- 应收/存货周转趋势
- 风险信号检查结果（红灯/黄灯数）

### D4. 前瞻与催化剂
- 短期/中期/长期催化剂
- 管理层指引解读
- 行业周期位置判断

### D5. 估值判断
- 相对估值（PE/PS/PEG/EV-EBITDA）
- 历史分位
- vs 同行

### D6. 综合结论
- 核心逻辑链（3-5条）
- Key Risks to Thesis（如果错了可能因为什么）
- 投资评级

## E-I. （根据篇幅灵活展开）

- E. 风险提示表

- H. 综合结论
- I. **交互引导** ⭐（必带！见下文）

## I. 交互引导 ⭐⭐⭐（每次输出必带！）

```markdown
---

## 🔄 接下来你想怎么深挖？

1. **竞品对比**：[公司] vs [同行A/B/C]
2. **业务线深挖**：深入某个具体业务
3. **估值建模**：DCF 或可比公司估值
4. **历史回溯**：过去2-3年的趋势演变
5. **压力测试**：悲观情景分析
6. **你提供新材料**：补充更多资料分析

或者直接告诉我你的想法 👇
```

## 使用指南

| 场景 | 使用方式 |
|------|---------|
| 首次分析新公司 | 完整模板 A→I |
| 快速季报点评 | A + B + C(精简) + D1 + H + I |
| 回答具体问题 | 只聚焦相关维度 |
| 迭代追问 | 只更新变化的部分 |

### 格式原则
1. **数字必须有参照系**（同比/环比/预期/同行）
2. **区分事实与判断**
3. **突出重点信息**（加粗/表格/emoji）
4. **保持语言简洁**
